#1 Multiples of 3 or 5

Find the sum of all the multiples of 3 or 5 below 1000.

Waiting for input...
// SOURCE CODE
const solve = () => {
    let sum = 0;
    for (let i = 0; i < 1000; i++) {
        if (i % 3 === 0 || i % 5 === 0) {
            sum += i;
        }
    }
    return sum;
};
