#29 Distinct Powers

How many distinct terms are in the sequence generated by a^b for 2 ≤ a ≤ 100 and 2 ≤ b ≤ 100?

Waiting for input...
// SOURCE CODE
const solve = () => {
    const terms = new Set();
    for (let a = 2; a <= 100; a++) {
        for (let b = 2; b <= 100; b++) {
            terms.add(BigInt(a) ** BigInt(b));
        }
    }
    return terms.size;
};
