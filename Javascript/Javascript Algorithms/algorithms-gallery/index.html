About Neon Algorithms

This collection showcases 60 fundamental algorithms from computer science, each implemented with pure vanilla JavaScript and rendered on HTML5 Canvas for interactive visualization.

Every algorithm is presented in its own dedicated HTML file with a cyberpunk-inspired neon aesthetic, making learning algorithms engaging and visually stunning.
