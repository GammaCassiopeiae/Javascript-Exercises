AABB & OBB Collision

Visualizing Axis-Aligned and Oriented Bounding Box collision detection.

AABB (Axis-Aligned Bounding Box)

AABBs are aligned with the coordinate axes. Collision is a simple check: (minA.x <= maxB.x && maxA.x >= minB.x) for all axes.

OBB (Oriented Bounding Box)

OBBs can be rotated. We use the Separating Axis Theorem (SAT): two convex shapes do not collide if there exists an axis on which their projections do not overlap. For two OBBs, there are 15 potential separating axes.
