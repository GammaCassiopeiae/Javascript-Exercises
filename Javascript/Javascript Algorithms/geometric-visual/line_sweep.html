Line Sweep Algorithm

Bentley–Ottmann Segment Intersection

The Bentley–Ottmann algorithm finds all intersections in a set of line segments. It uses a vertical sweep line that moves from left to right. Event points are segment endpoints and intersection points. It maintains a sorted list of segments currently intersecting the sweep line, allowing it to find intersections in O((n + k) log n) time, where k is the number of intersections.
