Ray Intersections

Visualizing intersections between rays and basic 3D primitives.

Ray-Sphere Intersection

A ray is defined as R(t) = O + tD. For a sphere with center C and radius r, we solve |R(t) - C|² = r². This leads to a quadratic equation at² + bt + c = 0.

Ray-Triangle Intersection (Möller–Trumbore)

This algorithm calculates the intersection of a ray with a triangle in 3D without needing the plane equation of the triangle. it uses barycentric coordinates (u, v).
