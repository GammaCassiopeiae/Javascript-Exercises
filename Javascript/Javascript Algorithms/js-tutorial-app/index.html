JavaScript Basics

JavaScript code can be embedded directly into HTML pages or stored in external files.

Variables & Datatypes

Variables are declared with the var keyword. JavaScript supports various datatypes including numbers, strings, booleans, and more.

Operators

JavaScript supports arithmetic, comparison, logical, and bitwise operators for manipulating values.

Control Structures

Control the flow of your program using if-else statements, switch-case, and loops.

Functions

Functions are reusable blocks of code that perform specific tasks. They can accept parameters and return values.

Events

Events are actions that happen in the browser, like clicks, mouse movements, or form submissions.

DOM Manipulation

The Document Object Model (DOM) allows JavaScript to interact with and modify HTML elements dynamically.

Objects & Arrays

Objects are collections of key-value pairs. Arrays are ordered lists of values.
