🔀 BFS

Breadth-First Search for Shortest Paths & Level Order

Quick Facts

  • Category: Tree & Graph Traversal
  • Time: O(V + E)
  • Space: O(V)
  • Best For: Shortest path (unweighted)
  • Data Structure: Queue

Key Use Cases

  • Shortest Path
  • Level Order Traversal
  • Connected Components
  • Bipartite Check
  • Word Ladder

Overview

BFS explores nodes level by level using a queue. Best for finding shortest paths in unweighted graphs. Visits all neighbors before moving to next level.

Key: Queue ensures FIFO order - neighbors visited in order they were discovered.

// BFS - Shortest Path in Unweighted Graph
function bfs(graph, start, target) {
    const queue = [[start, 0]];  // [node, distance]
    const visited = new Set([start]);
    
    while (queue.length > 0) {
        const [node, dist] = queue.shift();
        
        if (node === target) return dist;
        
        for (let neighbor of graph[node] || []) {
            if (!visited.has(neighbor)) {
                visited.add(neighbor);
                queue.push([neighbor, dist + 1]);
            }
        }
    }
    
    return -1;  // No path found
}

// Example
const graph = {
    1: [2, 3],
    2: [1, 4],
    3: [1, 5],
    4: [2],
    5: [3]
};

console.log(bfs(graph, 1, 5));  // 2 (path: 1→3→5)

Problem: Binary Tree Level Order Traversal

Return tree nodes grouped by level.

// BFS - Tree Level Order Traversal
function levelOrder(root) {
    if (!root) return [];
    
    const result = [];
    const queue = [root];
    
    while (queue.length > 0) {
        const levelSize = queue.length;
        const level = [];
        
        // Process all nodes at current level
        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift();
            level.push(node.val);
            
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
        
        result.push(level);
    }
    
    return result;
}

// Example
//     3
//    / \
//   9  20
//     /  \
//    15   7

// Output: [[3], [9, 20], [15, 7]]

Problem: Word Ladder

Find shortest transformation sequence from one word to another, changing one letter at a time.

// BFS - Word Ladder (Shortest Path)
function ladderLength(beginWord, endWord, wordList) {
    const wordSet = new Set(wordList);
    if (!wordSet.has(endWord)) return 0;
    
    const queue = [[beginWord, 1]];
    const visited = new Set([beginWord]);
    
    while (queue.length > 0) {
        const [word, steps] = queue.shift();
        
        if (word === endWord) return steps;
        
        // Generate all neighbors (change one letter)
        for (let i = 0; i < word.length; i++) {
            for (let c = 97; c <= 122; c++) {  // a-z
                const char = String.fromCharCode(c);
                if (char === word[i]) continue;
                
                const neighbor = word.slice(0, i) + char + word.slice(i + 1);
                
                if (wordSet.has(neighbor) && !visited.has(neighbor)) {
                    visited.add(neighbor);
                    queue.push([neighbor, steps + 1]);
                }
            }
        }
    }
    
    return 0;  // No transformation possible
}

// Example
// beginWord = "hit", endWord = "cog"
// wordList = ["hot","dot","dog","lot","log","cog"]
// Output: 5 (hit → hot → dot → dog → cog)

BFS vs DFS Comparison

  • BFS: Queue, level-by-level, shortest path (unweighted)
  • DFS: Stack/Recursion, depth-first, explores completely
  • Use BFS: Shortest paths, connected components, level queries
  • Use DFS: All paths, topological sort, backtracking

Key Insights

  • Queue Essential: FIFO order guarantees shortest path
  • Visited Set: Prevents revisiting nodes
  • Level Processing: Process all nodes at level before next
  • Distance Tracking: Keep distance with node in queue

Time & Space Complexity

  • Time: O(V + E) where V = vertices, E = edges
  • Space: O(V) for queue and visited set
  • Always Explores: Every node and edge once
