🔍 Binary Search

Finding Elements & Searching on Answer Spaces

Quick Facts

  • Category: Searching & Sorting
  • Time: O(log n)
  • Space: O(1)
  • Best For: Sorted arrays
  • Difficulty: Easy to Medium

Key Use Cases

  • Binary Search on Answer
  • Find Target in Sorted Array
  • Find First/Last Position
  • Search for Peak
  • Koko Eating Bananas

Overview

Binary search eliminates half of the remaining elements with each comparison. Works only on sorted data. Two main patterns: finding an exact value and "binary search on answer" where you search in a solution space.

Key: Maintain left and right pointers, calculate mid, and adjust based on comparison.

// Standard Binary Search - Find Target
function binarySearch(arr, target) {
    let left = 0;
    let right = arr.length - 1;
    
    while (left <= right) {
        const mid = Math.floor((left + right) / 2);
        
        if (arr[mid] === target) {
            return mid;  // Found
        } else if (arr[mid] < target) {
            left = mid + 1;  // Search right
        } else {
            right = mid - 1;  // Search left
        }
    }
    
    return -1;  // Not found
}

// Example
console.log(binarySearch([1, 3, 5, 7, 9, 11], 7));  // 3
console.log(binarySearch([1, 3, 5, 7, 9, 11], 8));  // -1

Problem: Find First and Last Position

Find the starting and ending position of a given target value in a sorted array.

// Find First and Last Position of Target
function searchRange(arr, target) {
    function findFirst(arr, target) {
        let left = 0, right = arr.length - 1;
        let result = -1;
        
        while (left <= right) {
            const mid = Math.floor((left + right) / 2);
            if (arr[mid] === target) {
                result = mid;
                right = mid - 1;  // Keep searching left
            } else if (arr[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        return result;
    }
    
    function findLast(arr, target) {
        let left = 0, right = arr.length - 1;
        let result = -1;
        
        while (left <= right) {
            const mid = Math.floor((left + right) / 2);
            if (arr[mid] === target) {
                result = mid;
                left = mid + 1;  // Keep searching right
            } else if (arr[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        return result;
    }
    
    return [findFirst(arr, target), findLast(arr, target)];
}

// Example
console.log(searchRange([5, 7, 7, 8, 8, 10], 8));  // [3, 4]
console.log(searchRange([5, 7, 7, 8, 8, 10], 6));  // [-1, -1]

Binary Search on Answer

Use binary search to find an optimal answer in a solution space rather than searching in an array.

// Binary Search on Answer - Koko Eating Bananas
function minEatingSpeed(piles, h) {
    function canFinish(speed) {
        let hours = 0;
        for (let pile of piles) {
            hours += Math.ceil(pile / speed);
        }
        return hours <= h;
    }
    
    let left = 1;
    let right = Math.max(...piles);
    
    while (left < right) {
        const mid = Math.floor((left + right) / 2);
        
        if (canFinish(mid)) {
            right = mid;  // Try slower speeds
        } else {
            left = mid + 1;  // Need faster speed
        }
    }
    
    return left;
}

// Example
console.log(minEatingSpeed([1, 1, 1, 1], 4));        // 1
console.log(minEatingSpeed([312884132], 968709470)); // 1

Key Insights

  • Invariant: target is always in [left, right]
  • Mid Calculation: Use Math.floor to avoid overflow
  • First/Last: Continue searching after finding target
  • Answer Space: Search space can be values, not just indices

Time & Space Complexity

  • Time: O(log n)
  • Space: O(1) iterative, O(log n) recursive
  • Iterations: At most log₂(n) iterations
