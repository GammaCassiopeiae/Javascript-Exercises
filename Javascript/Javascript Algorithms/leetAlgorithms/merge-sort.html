📊 Merge Sort

Stable O(n log n) Sorting with Divide and Conquer

Quick Facts

  • Category: Searching & Sorting
  • Time: O(n log n)
  • Space: O(n)
  • Stable: Yes
  • In-place: No

Key Use Cases

  • Stable Sorting
  • Divide & Conquer
  • Merge K Sorted Lists
  • Inversion Count
  • Merge Operations

Overview

Merge sort divides the array into halves, recursively sorts them, then merges sorted halves. Always O(n log n) and stable, but requires O(n) extra space.

Key: Divide problem into smaller subproblems, solve independently, merge results.

// Merge Sort - Divide and Conquer
function mergeSort(arr) {
    if (arr.length <= 1) return arr;
    
    const mid = Math.floor(arr.length / 2);
    const left = mergeSort(arr.slice(0, mid));
    const right = mergeSort(arr.slice(mid));
    
    return merge(left, right);
}

function merge(left, right) {
    const result = [];
    let i = 0, j = 0;
    
    while (i < left.length && j < right.length) {
        if (left[i] <= right[j]) {
            result.push(left[i++]);
        } else {
            result.push(right[j++]);
        }
    }
    
    return result.concat(left.slice(i), right.slice(j));
}

// Example
console.log(mergeSort([38, 27, 43, 3, 9, 82, 10]));
// [3, 9, 10, 27, 38, 43, 82]

Problem: Merge K Sorted Lists

Merge K sorted linked lists into one sorted list.

// Merge K Sorted Lists using Merge Sort approach
function mergeKLists(lists) {
    if (lists.length === 0) return null;
    
    function mergeTwoLists(l1, l2) {
        const dummy = new ListNode(0);
        let current = dummy;
        
        while (l1 && l2) {
            if (l1.val <= l2.val) {
                current.next = l1;
                l1 = l1.next;
            } else {
                current.next = l2;
                l2 = l2.next;
            }
            current = current.next;
        }
        
        current.next = l1 || l2;
        return dummy.next;
    }
    
    function mergeLists(lists, left, right) {
        if (left === right) return lists[left];
        if (left > right) return null;
        
        const mid = Math.floor((left + right) / 2);
        const l1 = mergeLists(lists, left, mid);
        const l2 = mergeLists(lists, mid + 1, right);
        
        return mergeTwoLists(l1, l2);
    }
    
    return mergeLists(lists, 0, lists.length - 1);
}

// Time: O(n log k) where n = total nodes, k = number of lists
// Space: O(log k) for recursion

Count Inversions using Merge Sort

Count inversions (pairs where i < j but arr[i] > arr[j]).

// Count Inversions using Merge Sort
function countInversions(arr) {
    let inversions = 0;
    
    function mergeSortAndCount(left, right) {
        if (left >= right) return arr.slice(left, right + 1);
        
        const mid = Math.floor((left + right) / 2);
        const leftArr = mergeSortAndCount(left, mid);
        const rightArr = mergeSortAndCount(mid + 1, right);
        
        return mergeAndCount(leftArr, rightArr);
    }
    
    function mergeAndCount(left, right) {
        const result = [];
        let i = 0, j = 0;
        
        while (i < left.length && j < right.length) {
            if (left[i] <= right[j]) {
                result.push(left[i++]);
            } else {
                // All remaining elements in left are inversions
                inversions += left.length - i;
                result.push(right[j++]);
            }
        }
        
        return result.concat(left.slice(i), right.slice(j));
    }
    
    mergeSortAndCount(0, arr.length - 1);
    return inversions;
}

// Example
console.log(countInversions([1, 3, 2, 4]));  // 1 (pair (3,2))

Key Insights

  • Stability: Preserves order of equal elements
  • Guaranteed O(n log n): No worst case degradation
  • Space Trade-off: O(n) extra space for stability
  • Merge Operation: Core of the algorithm

Time & Space Complexity

  • Time: O(n log n) all cases
  • Space: O(n) for temporary arrays
  • Recurrence: T(n) = 2T(n/2) + O(n)
