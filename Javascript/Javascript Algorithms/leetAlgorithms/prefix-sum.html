⚡ Prefix Sum

O(1) Range Queries with O(n) Preprocessing

Quick Facts

  • Category: Linear Data Structures
  • Build: O(n)
  • Query: O(1)
  • Space: O(n)
  • Best For: Range sum queries

Key Use Cases

  • Range Sum Query
  • Subarray Sum
  • 2D Matrix Sum
  • Continuous Subarray Sum
  • Subarrays with Sum K

Overview

Prefix sum stores cumulative sums up to each index. Instead of calculating sum from index i to j by iterating, you can answer in O(1) using: sum(i, j) = prefix[j+1] - prefix[i].

Trade-off: O(n) space and preprocessing time for O(1) query time.

// Basic Prefix Sum
function buildPrefixSum(arr) {
    const prefix = [0];
    
    for (let num of arr) {
        prefix.push(prefix[prefix.length - 1] + num);
    }
    
    return prefix;
}

function rangeSum(prefix, left, right) {
    // Sum of elements from index left to right (inclusive)
    return prefix[right + 1] - prefix[left];
}

// Example
const arr = [1, 2, 3, 4, 5];
const prefix = buildPrefixSum(arr);
// prefix = [0, 1, 3, 6, 10, 15]

console.log(rangeSum(prefix, 1, 3));  // 2+3+4 = 9
console.log(rangeSum(prefix, 0, 4));  // 1+2+3+4+5 = 15

Problem: Range Sum Query - Immutable

Design a class that supports sum of subarrays for multiple queries.

// NumArray Class with Prefix Sum
class NumArray {
    constructor(nums) {
        this.prefix = [0];
        
        for (let num of nums) {
            this.prefix.push(this.prefix[this.prefix.length - 1] + num);
        }
    }
    
    sumRange(left, right) {
        return this.prefix[right + 1] - this.prefix[left];
    }
}

// Usage
const na = new NumArray([-2, 0, 3, -5, 2, -1]);
console.log(na.sumRange(0, 2));   // -2+0+3 = 1
console.log(na.sumRange(2, 5));   // 3+(-5)+2+(-1) = -1
console.log(na.sumRange(0, 5));   // -2+0+3+(-5)+2+(-1) = -3

Problem: Subarray Sum Equals K

Count number of subarrays with sum equal to k.

// Subarrays with Sum = K using Prefix Sum + HashMap
function subarraySum(nums, k) {
    const prefixCount = {0: 1};  // Start with prefix 0
    let currentSum = 0;
    let count = 0;
    
    for (let num of nums) {
        currentSum += num;
        
        // If (currentSum - k) exists, we found valid subarrays
        if (prefixCount[currentSum - k] !== undefined) {
            count += prefixCount[currentSum - k];
        }
        
        // Add current prefix sum to map
        prefixCount[currentSum] = (prefixCount[currentSum] || 0) + 1;
    }
    
    return count;
}

// Example
console.log(subarraySum([1, 1, 1], 2));  // 2 (subarrays [1,1])
console.log(subarraySum([1, 2, 3], 3));  // 2 (subarrays [3] and [1,2])

2D Prefix Sum

Extension for 2D arrays to answer rectangular region sum queries.

// 2D Prefix Sum for Matrix Range Queries
class NumMatrix {
    constructor(matrix) {
        const rows = matrix.length;
        const cols = matrix[0]?.length || 0;
        
        // Build 2D prefix sum: prefix[i][j] = sum of matrix[0..i-1][0..j-1]
        this.prefix = Array(rows + 1).fill(0).map(() => Array(cols + 1).fill(0));
        
        for (let i = 1; i <= rows; i++) {
            for (let j = 1; j <= cols; j++) {
                this.prefix[i][j] = 
                    matrix[i-1][j-1] + 
                    this.prefix[i-1][j] + 
                    this.prefix[i][j-1] - 
                    this.prefix[i-1][j-1];
            }
        }
    }
    
    sumRegion(row1, col1, row2, col2) {
        // Sum of rectangle from (row1,col1) to (row2,col2)
        return this.prefix[row2+1][col2+1]
             - this.prefix[row1][col2+1]
             - this.prefix[row2+1][col1]
             + this.prefix[row1][col1];
    }
}

// Example
const matrix = [[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]];
const nm = new NumMatrix(matrix);
console.log(nm.sumRegion(2, 1, 4, 3));  // 8

Key Insights

  • Index Offset: Prefix[i] represents sum of arr[0..i-1]
  • Range Query: sum(i, j) = prefix[j+1] - prefix[i]
  • Prefix + HashMap: Solve "sum equals k" problems
  • 2D Extension: Use inclusion-exclusion principle

Time & Space Complexity

  • Build: O(n) for 1D, O(n*m) for 2D
  • Query: O(1) for both 1D and 2D
  • Space: O(n) for 1D, O(n*m) for 2D
