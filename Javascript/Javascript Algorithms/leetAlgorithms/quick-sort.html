⚡ Quick Sort

In-place Sorting with O(n log n) Average Time

Quick Facts

  • Category: Searching & Sorting
  • Time: O(n log n) avg, O(n²) worst
  • Space: O(log n)
  • Stable: No
  • In-place: Yes

Key Properties

  • Partition-based
  • Divide and Conquer
  • Cache-friendly
  • Practical sorting
  • Used in std::sort

Overview

Quick sort selects a pivot element and partitions the array into smaller and larger elements. Recursively sorts partitions. Average O(n log n) but worst case O(n²) with bad pivot selection.

Key: Partition strategy and pivot selection determine performance.

// Quick Sort - In-place Sorting
function quickSort(arr, left = 0, right = arr.length - 1) {
    if (left < right) {
        const pi = partition(arr, left, right);
        quickSort(arr, left, pi - 1);
        quickSort(arr, pi + 1, right);
    }
    return arr;
}

function partition(arr, left, right) {
    const pivot = arr[right];
    let i = left - 1;
    
    for (let j = left; j < right; j++) {
        if (arr[j] < pivot) {
            i++;
            [arr[i], arr[j]] = [arr[j], arr[i]];
        }
    }
    
    [arr[i + 1], arr[right]] = [arr[right], arr[i + 1]];
    return i + 1;
}

// Example
const arr = [38, 27, 43, 3, 9, 82, 10];
console.log(quickSort([...arr]));
// [3, 9, 10, 27, 38, 43, 82]

Pivot Selection Strategies

Pivot choice significantly impacts performance:

// Quick Sort with Random Pivot (Better Average Case)
function quickSortRandom(arr, left = 0, right = arr.length - 1) {
    if (left < right) {
        const pi = partitionRandom(arr, left, right);
        quickSortRandom(arr, left, pi - 1);
        quickSortRandom(arr, pi + 1, right);
    }
    return arr;
}

function partitionRandom(arr, left, right) {
    // Pick random pivot
    const randomIdx = left + Math.floor(Math.random() * (right - left + 1));
    [arr[randomIdx], arr[right]] = [arr[right], arr[randomIdx]];
    
    const pivot = arr[right];
    let i = left - 1;
    
    for (let j = left; j < right; j++) {
        if (arr[j] < pivot) {
            i++;
            [arr[i], arr[j]] = [arr[j], arr[i]];
        }
    }
    
    [arr[i + 1], arr[right]] = [arr[right], arr[i + 1]];
    return i + 1;
}

// Median-of-Three Pivot
function getMedianOfThree(arr, left, right) {
    const mid = Math.floor((left + right) / 2);
    
    if (arr[left] > arr[mid]) [arr[left], arr[mid]] = [arr[mid], arr[left]];
    if (arr[left] > arr[right]) [arr[left], arr[right]] = [arr[right], arr[left]];
    if (arr[mid] > arr[right]) [arr[mid], arr[right]] = [arr[right], arr[mid]];
    
    return mid;
}

Worst Case Scenario

Quick sort degrades to O(n²) when pivot is always the smallest or largest element (already sorted arrays with last element pivot).

// - Space is limited

Key Insights

  • Pivot Critical: Random or median-of-three improves average case
  • In-place: Only needs O(log n) stack space
  • Not Stable: Order of equal elements not preserved
  • Practical Choice: Most libraries use hybrid approaches

Time & Space Complexity

  • Best: O(n log n) balanced partitions
  • Average: O(n log n) with random pivot
  • Worst: O(n²) with bad pivot selection
  • Space: O(log n) recursion stack
