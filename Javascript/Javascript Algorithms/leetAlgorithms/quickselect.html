⚡ Quickselect

Find K-th Smallest Element in O(n) Average Time

Quick Facts

  • Category: Searching & Sorting
  • Time: O(n) avg, O(n²) worst
  • Space: O(log n)
  • Best For: Finding K-th element
  • Difficulty: Medium

Key Use Cases

  • K-th Largest Element
  • K-th Smallest Element
  • Median of Stream
  • Top K Elements

Overview

Quickselect uses the partition function from Quicksort. Instead of fully sorting, it focuses on finding the K-th element by recursively partitioning around a pivot.

Advantage: Faster than sorting for finding single K-th element (O(n) vs O(n log n)).

// Quickselect - Find K-th Smallest Element
function findKthSmallest(arr, k) {
    function quickSelect(left, right, kSmallest) {
        if (left === right) return arr[left];
        
        const pivotIdx = partition(left, right);
        
        if (kSmallest === pivotIdx) {
            return arr[kSmallest];
        } else if (kSmallest < pivotIdx) {
            return quickSelect(left, pivotIdx - 1, kSmallest);
        } else {
            return quickSelect(pivotIdx + 1, right, kSmallest);
        }
    }
    
    function partition(left, right) {
        const pivot = arr[right];
        let i = left;
        
        for (let j = left; j < right; j++) {
            if (arr[j] < pivot) {
                [arr[i], arr[j]] = [arr[j], arr[i]];
                i++;
            }
        }
        
        [arr[i], arr[right]] = [arr[right], arr[i]];
        return i;
    }
    
    // Convert k to 0-indexed (k=1 → index 0)
    return quickSelect(0, arr.length - 1, k - 1);
}

// Example
console.log(findKthSmallest([3, 2, 1, 5, 6, 4], 2));  // 2
console.log(findKthSmallest([3, 2, 3, 1, 2, 4, 5, 5, 6], 4));  // 4

Problem: K-th Largest Element

Find the K-th largest element in an array.

// K-th Largest Element using Quickselect
function findKthLargest(arr, k) {
    function quickSelect(left, right, kIndex) {
        if (left === right) return arr[left];
        
        const pivotIdx = partition(left, right);
        
        if (kIndex === pivotIdx) {
            return arr[kIndex];
        } else if (kIndex < pivotIdx) {
            return quickSelect(left, pivotIdx - 1, kIndex);
        } else {
            return quickSelect(pivotIdx + 1, right, kIndex);
        }
    }
    
    function partition(left, right) {
        const pivot = arr[right];
        let i = left;
        
        for (let j = left; j < right; j++) {
            if (arr[j] > pivot) {  // Note: > for largest
                [arr[i], arr[j]] = [arr[j], arr[i]];
                i++;
            }
        }
        
        [arr[i], arr[right]] = [arr[right], arr[i]];
        return i;
    }
    
    return quickSelect(0, arr.length - 1, k - 1);
}

// Example
console.log(findKthLargest([3, 2, 1, 5, 6, 4], 2));  // 5
console.log(findKthLargest([3, 2, 3, 1], 1));  // 3

Comparison with Heap

Quickselect: O(n) average, O(n²) worst case

Min-Heap: O(n log k) always, better for very small k

Max-Heap: O(n + k log n) for finding all top k elements

// Quickselect with Random Pivot (Improves Average Case)
function findKthLargestRandom(arr, k) {
    function quickSelect(left, right, kIndex) {
        if (left === right) return arr[left];
        
        const pivotIdx = partitionRandom(left, right);
        
        if (kIndex === pivotIdx) {
            return arr[kIndex];
        } else if (kIndex < pivotIdx) {
            return quickSelect(left, pivotIdx - 1, kIndex);
        } else {
            return quickSelect(pivotIdx + 1, right, kIndex);
        }
    }
    
    function partitionRandom(left, right) {
        const randomIdx = left + Math.floor(Math.random() * (right - left + 1));
        [arr[randomIdx], arr[right]] = [arr[right], arr[randomIdx]];
        
        const pivot = arr[right];
        let i = left;
        
        for (let j = left; j < right; j++) {
            if (arr[j] > pivot) {
                [arr[i], arr[j]] = [arr[j], arr[i]];
                i++;
            }
        }
        
        [arr[i], arr[right]] = [arr[right], arr[i]];
        return i;
    }
    
    return quickSelect(0, arr.length - 1, k - 1);
}

// Time: O(n) average, Space: O(log n)

Key Insights

  • Pivot Selection: Random pivot improves average case
  • Index vs Element: Find index of k-th element, not k
  • Largest/Smallest: Reverse comparison for largest
  • Better than Sorting: O(n) vs O(n log n)

Time & Space Complexity

  • Time: O(n) average, O(n²) worst case
  • Space: O(log n) for recursion stack
  • In-place: Yes, modifies input array
