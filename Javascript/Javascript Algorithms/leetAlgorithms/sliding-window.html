🪟 Sliding Window

Find Subarrays & Substrings Efficiently

Quick Facts

  • Category: Linear Data Structures
  • Time: O(n)
  • Space: O(k)
  • Best For: Contiguous subarrays/substrings
  • Difficulty: Medium

Key Use Cases

  • Longest Substring
  • Maximum Sum Subarray
  • Minimum Window
  • Fruit Into Baskets
  • Permutation in String

Overview

Sliding window is a technique where you create a window of fixed or variable size that slides through an array or string. Instead of recalculating sums for overlapping subarrays, you expand and shrink the window dynamically.

Pattern: Two pointers (left/right) expand the window, shrink when condition fails, track result at each step.

// Fixed-size Sliding Window
function maxSumSubarray(arr, k) {
    let maxSum = 0;
    let currentSum = 0;
    
    // Calculate sum of first window
    for (let i = 0; i < k; i++) {
        currentSum += arr[i];
    }
    maxSum = currentSum;
    
    // Slide the window
    for (let i = k; i < arr.length; i++) {
        currentSum = currentSum - arr[i - k] + arr[i];
        maxSum = Math.max(maxSum, currentSum);
    }
    
    return maxSum;
}

// Example
console.log(maxSumSubarray([1, 4, 2, 10, 2, 3, 1, 0, 20], 4));
// Output: 24 (subarray [10, 2, 3, 1] + some overlap)

Problem: Longest Substring Without Repeating Characters

Find the length of the longest substring without repeating characters.

// Variable-size Sliding Window
function lengthOfLongestSubstring(s) {
    const charIndex = {};  // Map of char -> last index
    let maxLen = 0;
    let left = 0;
    
    for (let right = 0; right < s.length; right++) {
        // If char seen and within window, move left
        if (s[right] in charIndex && charIndex[s[right]] >= left) {
            left = charIndex[s[right]] + 1;
        }
        
        // Record the character's position
        charIndex[s[right]] = right;
        
        // Update max length
        maxLen = Math.max(maxLen, right - left + 1);
    }
    
    return maxLen;
}

// Example
console.log(lengthOfLongestSubstring("abcabcbb"));
// Output: 3 (substring "abc")
console.log(lengthOfLongestSubstring("bbbbb"));
// Output: 1 (substring "b")

Problem: Minimum Window Substring

Find the smallest substring containing all characters of a pattern.

// Minimum Window Substring with Character Count
function minWindow(s, t) {
    if (t.length > s.length) return "";
    
    const tCount = {};
    for (let char of t) {
        tCount[char] = (tCount[char] || 0) + 1;
    }
    
    const windowCount = {};
    let formed = 0;  // Number of unique chars with desired frequency
    let required = Object.keys(tCount).length;
    
    let left = 0, right = 0;
    let minLen = Infinity;
    let minStart = 0;
    
    while (right < s.length) {
        // Add character from right
        const char = s[right];
        windowCount[char] = (windowCount[char] || 0) + 1;
        
        // If frequency matches, increment formed
        if (char in tCount && windowCount[char] === tCount[char]) {
            formed++;
        }
        
        // Try to contract window
        while (left <= right && formed === required) {
            // Update result if window is smaller
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                minStart = left;
            }
            
            // Remove character from left
            const leftChar = s[left];
            windowCount[leftChar]--;
            if (leftChar in tCount && windowCount[leftChar] < tCount[leftChar]) {
                formed--;
            }
            
            left++;
        }
        
        right++;
    }
    
    return minLen === Infinity ? "" : s.substring(minStart, minStart + minLen);
}

// Example
console.log(minWindow("ADOBECODEBANC", "ABC"));
// Output: "BANC"

Key Insights

  • Two Pointers: Expand with right, contract with left pointer
  • Condition-Based: Keep expanding until condition met, then shrink
  • Hash Map/Set: Track characters or elements in current window
  • Update Result: Check result at every valid window state

Time & Space Complexity

  • Time: O(n) where n is length of string
  • Space: O(k) where k is size of character set
  • Why O(n)?: Each element visited at most twice (once by right, once by left)
