🔢 Add Digits

Given an integer num, repeatedly add all its digits until the result has only one digit, and return it. This is also known as the digital root of a number.

⏱️ Time: O(1) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function addDigits(num) {
  // Method 1: Mathematical formula (O(1))
  // Digital root formula: dr(n) = 1 + (n-1) % 9
  if (num === 0) return 0;
  return 1 + (num - 1) % 9;
}

// Method 2: Iterative approach
function addDigitsIterative(num) {
  while (num >= 10) {
    let sum = 0;
    while (num > 0) {
      sum += num % 10;
      num = Math.floor(num / 10);
    }
    num = sum;
  }
  return num;
}

📖 Algorithm Explanation

  • The digital root follows a pattern based on modulo 9.
  • Formula: digital_root(n) = 1 + (n-1) % 9 for n > 0.
  • This works because the sum of digits preserves the remainder mod 9.
  • Alternative: iteratively sum digits until single digit remains.

📝 Example Walkthrough

Input: num = 38

Iterative approach:
38 → 3 + 8 = 11
11 → 1 + 1 = 2

Result: 2

Using formula:
1 + (38 - 1) % 9
= 1 + 37 % 9
= 1 + 1
= 2
