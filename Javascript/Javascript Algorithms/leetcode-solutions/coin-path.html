🪙 Coin Path

Given an array of coins (where -1 means unreachable) and a maximum jump distance B, find the cheapest path from index 0 to the last index. Return the indices of the path. If multiple paths have the same cost, return the lexicographically smallest one.

⏱️ Time: O(n × B) 💾 Space: O(n) 📊 Difficulty: Hard

💻 Solution Code

JavaScript 
function cheapestJump(coins, B) {
  const n = coins.length;
  const dp = new Array(n).fill(Infinity);
  const next = new Array(n).fill(-1);
  
  dp[n - 1] = coins[n - 1];
  
  for (let i = n - 2; i >= 0; i--) {
    if (coins[i] === -1) continue;
    
    for (let j = 1; j <= B && i + j < n; j++) {
      if (dp[i + j] !== Infinity) {
        const cost = coins[i] + dp[i + j];
        if (cost < dp[i] || (cost === dp[i] && (next[i] === -1 || i + j < next[i]))) {
          dp[i] = cost;
          next[i] = i + j;
        }
      }
    }
  }
  
  if (dp[0] === Infinity) return [];
  
  const path = [];
  let curr = 0;
  while (curr !== -1) {
    path.push(curr + 1); // 1-indexed
    curr = next[curr];
  }
  
  return path;
}

📖 Algorithm Explanation

  • Use dynamic programming from right to left.
  • dp[i] = minimum cost to reach the end from index i.
  • For each position, try all jumps from 1 to B.
  • Track the next index for path reconstruction.
  • Choose lexicographically smallest path when costs are equal.

📝 Example Walkthrough

Input: coins = [1,2,4,-1,2,1], B = 2

Indices:  0  1  2   3  4  5
Coins:    1  2  4  -1  2  1

DP (right to left):
dp[5] = 1
dp[4] = 2 + 1 = 3
dp[3] = -1 (unreachable)
dp[2] = min(4+dp[4], 4+dp[3]) = 4+3 = 7
dp[1] = min(2+dp[2], 2+dp[3]) = 2+7 = 9
dp[0] = min(1+dp[1], 1+dp[2]) = 1+7 = 8

Path: 0 → 2 → 4 → 5
Result (1-indexed): [1, 3, 5, 6]
