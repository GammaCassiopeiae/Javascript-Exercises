📦 Decompress Run-Length Encoded List

We are given a list nums of integers representing a list compressed with run-length encoding. Consider each adjacent pair [freq, val] and decompress by generating freq copies of val. Concatenate all sublists to form the decompressed list.

⏱️ Time: O(n) 💾 Space: O(n) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function decompressRLElist(nums) {
  const result = [];
  
  // Process pairs [freq, val]
  for (let i = 0; i < nums.length; i += 2) {
    const freq = nums[i];
    const val = nums[i + 1];
    
    // Add val, freq times
    for (let j = 0; j < freq; j++) {
      result.push(val);
    }
  }
  
  return result;
}

📖 Algorithm Explanation

  • Process the array in pairs: [frequency, value].
  • For each pair, add 'value' to result 'frequency' times.
  • Continue until all pairs are processed.
  • Return the concatenated result.

📝 Example Walkthrough

Input: nums = [1,2,3,4]

Pairs: [1,2], [3,4]

Decompression:
- [1,2]: Add 2, 1 time → [2]
- [3,4]: Add 4, 3 times → [2,4,4,4]

Result: [2, 4, 4, 4]

Input: [2,1,1,3]
Pairs: [2,1], [1,3]
- [2,1]: Add 1, 2 times → [1,1]
- [1,3]: Add 3, 1 time → [1,1,3]

Result: [1, 1, 3]
