📊 Delete Columns to Make Sorted

You are given an array of n strings, each of the same length. The strings can be arranged in a grid. Delete columns that are not sorted lexicographically. Return the number of columns to delete.

⏱️ Time: O(m × n) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function minDeletionSize(strs) {
  const m = strs.length;
  const n = strs[0].length;
  let deleteCount = 0;
  
  // Check each column
  for (let col = 0; col < n; col++) {
    // Check if column is sorted
    for (let row = 1; row < m; row++) {
      if (strs[row][col] < strs[row - 1][col]) {
        deleteCount++;
        break;
      }
    }
  }
  
  return deleteCount;
}

📖 Algorithm Explanation

  • Iterate through each column of the grid.
  • For each column, check if characters are sorted top to bottom.
  • If any character is less than the one above it, the column is unsorted.
  • Count and return the number of unsorted columns.
