🚇 Design Underground System

Design an underground system that tracks customer travel times between stations and calculates average travel time between any two stations. Support checkIn, checkOut, and getAverageTime operations.

⏱️ Time: O(1) 💾 Space: O(n) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
class UndergroundSystem {
  constructor() {
    this.checkIns = new Map(); // id → {station, time}
    this.routes = new Map(); // "start→end" → {total, count}
  }

  checkIn(id, stationName, t) {
    this.checkIns.set(id, { station: stationName, time: t });
  }

  checkOut(id, stationName, t) {
    const checkIn = this.checkIns.get(id);
    const route = `${checkIn.station}→${stationName}`;
    const travelTime = t - checkIn.time;
    
    if (!this.routes.has(route)) {
      this.routes.set(route, { total: 0, count: 0 });
    }
    const r = this.routes.get(route);
    r.total += travelTime;
    r.count++;
    
    this.checkIns.delete(id);
  }

  getAverageTime(startStation, endStation) {
    const route = `${startStation}→${endStation}`;
    const r = this.routes.get(route);
    return r.total / r.count;
  }
}

📖 Algorithm Explanation

  • Use a hash map to track active check-ins (id → station, time).
  • Use another hash map to accumulate travel times per route.
  • On checkOut, calculate travel time and update route statistics.
  • Average time = total time / count for each route.
  • All operations are O(1) time complexity.
