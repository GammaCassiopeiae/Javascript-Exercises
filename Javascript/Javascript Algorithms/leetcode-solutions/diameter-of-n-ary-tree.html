🌳 Diameter of N-ary Tree

Given the root of an N-ary tree, find the diameter (the number of nodes in the longest path between any two nodes). The path may or may not pass through the root.

⏱️ Time: O(n) 💾 Space: O(h) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
class Node {
  constructor(val, children = []) {
    this.val = val;
    this.children = children;
  }
}

function diameter(root) {
  let maxDiameter = 0;
  
  function height(node) {
    if (!node) return 0;
    
    let max1 = 0, max2 = 0;
    
    // Find two longest paths from this node
    for (let child of node.children) {
      const h = height(child);
      if (h > max1) {
        max2 = max1;
        max1 = h;
      } else if (h > max2) {
        max2 = h;
      }
    }
    
    // Update diameter through this node
    maxDiameter = Math.max(maxDiameter, max1 + max2);
    
    return max1 + 1;
  }
  
  height(root);
  return maxDiameter;
}

📖 Algorithm Explanation

  • Use DFS to calculate the height of each subtree.
  • For each node, track the two longest paths from its children.
  • The diameter through a node is the sum of these two longest paths.
  • Keep track of the maximum diameter found across all nodes.

📝 Example Walkthrough

Input: Tree represented as [1,null,3,2,4,null,5,6]

Longest path: 5 → 3 → 6 (or 6 → 3 → 5)
