🍽️ Display Table of Food Orders

Given orders from restaurant customers, generate a display table. The table shows how many of each food item each table ordered. First column is table number, then food items in alphabetical order.

⏱️ Time: O(n log n + m log m) 💾 Space: O(n * m) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function displayTable(orders) {
  const tableMap = new Map();  // table -> {food -> count}
  const foodSet = new Set();

  // Process all orders
  for (const [customer, table, food] of orders) {
    if (!tableMap.has(table)) {
      tableMap.set(table, {});
    }
    const tableOrders = tableMap.get(table);
    tableOrders[food] = (tableOrders[food] || 0) + 1;
    foodSet.add(food);
  }

  // Sort tables numerically and foods alphabetically
  const tables = Array.from(tableMap.keys()).sort((a, b) => parseInt(a) - parseInt(b));
  const foods = Array.from(foodSet).sort();

  // Build result table
  const result = [];
  
  // Header row
  result.push(["Table", ...foods]);

  // Data rows
  for (const table of tables) {
    const row = [table];
    const tableOrders = tableMap.get(table);
    for (const food of foods) {
      row.push((tableOrders[food] || 0).toString());
    }
    result.push(row);
  }

  return result;
}

📖 Algorithm Explanation

  • Use a Map to track each table's orders (table number -> food counts).
  • Use a Set to collect all unique food items.
  • Sort tables numerically and food items alphabetically.
  • Build the result table with header row and data rows for each table.
