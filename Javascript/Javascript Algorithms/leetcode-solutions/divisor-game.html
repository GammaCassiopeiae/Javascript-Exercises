🎮 Divisor Game

Alice and Bob take turns playing a game. Starting with n, each player chooses x where 0 < x < n and n % x == 0, then replaces n with n - x. The player who cannot make a move loses. Return true if Alice wins (she goes first).

⏱️ Time: O(1) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function divisorGame(n) {
  // Mathematical insight: Alice wins if n is even
  // Proof by induction:
  // - n=1: Alice loses (no valid move)
  // - n=2: Alice chooses 1, Bob gets 1, Bob loses
  // - If n is even, Alice can always choose 1,
  //   giving Bob an odd number
  // - If n is odd, all divisors are odd,
  //   so n-x is even (Bob gets even)
  
  return n % 2 === 0;
}

📖 Algorithm Explanation

  • Key insight: Alice wins if and only if n is even.
  • If n is even, Alice can always choose x=1, giving Bob an odd number.
  • If n is odd, all its divisors are odd, so n-x will be even (Bob gets even).
  • Eventually, the player with odd numbers will get n=1 and lose.

📝 Example Walkthrough 

n = 10 (even) → Alice wins!

Sample game play:
n=10 (Alice): chooses 1 → n=9
n=9 (Bob): chooses 1 or 3 → n=8 or n=6
n=8 (Alice): chooses 1 → n=7
n=7 (Bob): chooses 1 → n=6
n=6 (Alice): chooses 1 → n=5
n=5 (Bob): chooses 1 → n=4
n=4 (Alice): chooses 1 → n=3
n=3 (Bob): chooses 1 → n=2
n=2 (Alice): chooses 1 → n=1
n=1 (Bob): No valid move → Bob loses!
