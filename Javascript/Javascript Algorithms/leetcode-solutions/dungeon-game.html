🏰 Dungeon Game

The knight starts at top-left and must reach the princess at bottom-right. Each cell has a value (negative = demon, positive = orb). The knight dies if health drops to 0 or below. Find minimum initial health needed.

⏱️ Time: O(m × n) 💾 Space: O(m × n) 📊 Difficulty: Hard

💻 Solution Code

JavaScript 
function calculateMinimumHP(dungeon) {
  const m = dungeon.length, n = dungeon[0].length;
  const dp = Array.from({ length: m }, 
    () => new Array(n).fill(Infinity));
  
  // Base case: need at least 1 health at princess
  dp[m - 1][n - 1] = Math.max(1, 1 - dungeon[m - 1][n - 1]);
  
  // Fill from bottom-right to top-left
  for (let i = m - 1; i >= 0; i--) {
    for (let j = n - 1; j >= 0; j--) {
      if (i === m - 1 && j === n - 1) continue;
      
      const fromRight = j + 1 < n ? dp[i][j + 1] : Infinity;
      const fromDown = i + 1 < m ? dp[i + 1][j] : Infinity;
      
      dp[i][j] = Math.max(1, Math.min(fromRight, fromDown) - dungeon[i][j]);
    }
  }
  
  return dp[0][0];
}

📖 Algorithm Explanation

  • Use DP from bottom-right to top-left (reverse direction).
  • dp[i][j] = minimum health needed at cell (i,j) to reach princess alive.
  • At each cell, need enough health to survive and reach next cell.
  • Minimum health at any point is 1 (can't be 0 or negative).
