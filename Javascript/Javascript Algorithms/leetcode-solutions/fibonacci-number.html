🌀 Fibonacci Number

The Fibonacci sequence: F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2). Given n, calculate the nth Fibonacci number. Each number is the sum of the two preceding ones.

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Easy

🎯 Input

📈 Result

💻 Solution Code

JavaScript 
function fib(n) {
  if (n <= 1) return n;
  
  let prev2 = 0;  // F(0)
  let prev1 = 1;  // F(1)
  
  // Iteratively build up to F(n)
  for (let i = 2; i <= n; i++) {
    const current = prev1 + prev2;
    prev2 = prev1;
    prev1 = current;
  }
  
  return prev1;
}

// Alternative: Matrix exponentiation O(log n)
// Or Binet's formula with floating point

📖 Algorithm Explanation

  • Base cases: F(0) = 0, F(1) = 1.
  • For n ≥ 2, iteratively compute each Fibonacci number using the previous two.
  • Keep track of only the last two values (O(1) space).
  • Each iteration: current = prev1 + prev2, then shift values.
