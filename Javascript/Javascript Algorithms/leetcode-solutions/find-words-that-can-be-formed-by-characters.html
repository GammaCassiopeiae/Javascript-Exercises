📝 Find Words That Can Be Formed by Characters

You are given an array of strings words and a string chars. A string is good if it can be formed by characters from chars (each character can only be used once). Return the sum of lengths of all good strings.

⏱️ Time: O(n × m) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function countCharacters(words, chars) {
  // Count character frequencies in chars
  const charCount = new Map();
  for (const c of chars) {
    charCount.set(c, (charCount.get(c) || 0) + 1);
  }
  
  let totalLength = 0;
  
  for (const word of words) {
    const wordCount = new Map();
    let canForm = true;
    
    for (const c of word) {
      wordCount.set(c, (wordCount.get(c) || 0) + 1);
      if ((wordCount.get(c) || 0) > (charCount.get(c) || 0)) {
        canForm = false;
        break;
      }
    }
    
    if (canForm) {
      totalLength += word.length;
    }
  }
  
  return totalLength;
}

📖 Algorithm Explanation

  • Count frequency of each character in chars.
  • For each word, count its character frequencies.
  • Check if word can be formed (each char count ≤ available).
  • If yes, add word length to total.

📝 Example Walkthrough

Input: words = ["cat","bt","hat","tree"], chars = "ataach"

Character counts in "ataach":
a: 3, t: 1, c: 1, h: 1

Checking each word:
- "cat": needs c:1, a:1, t:1 → ✓ Can form (length 3)
- "bt": needs b:1, t:1 → ✗ No 'b' available
- "hat": needs h:1, a:1, t:1 → ✓ Can form (length 3)
- "tree": needs t:1, r:1, e:2 → ✗ No 'r' or 'e'

Good words: "cat", "hat"
Sum of lengths: 3 + 3 = 6
