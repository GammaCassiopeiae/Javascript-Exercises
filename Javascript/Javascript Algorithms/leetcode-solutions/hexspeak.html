Hexspeak

LeetCode Problem - Hexadecimal Conversion

Problem Description

Hexspeak is a representation of decimal numbers where hex digits 0-9 are replaced with O-I-Z-S-E-h-B-g. Return ERROR if any invalid digit appears.

JavaScript Solution

function toHexspeak(num) {
    // Convert to hexadecimal
    const hex = parseInt(num).toString(16).toUpperCase();
    
    const map = {
        '0': 'O',
        '1': 'I',
        '5': 'S',
        '6': 'G',
        '7': 'L',
        '9': 'G',
        'A': 'A',
        'B': 'B',
        'C': 'C',
        'D': 'D',
        'E': 'E',
        'F': 'F'
    };
    
    let result = '';
    for (const c of hex) {
        if (!map.hasOwnProperty(c)) {
            return "ERROR";
        }
        result += map[c];
    }
    
    return result;
}

// Usage Example:
console.log(toHexspeak("257")); // "IOI" (257 = 0x101)
