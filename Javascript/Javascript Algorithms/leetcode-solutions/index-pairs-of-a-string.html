📍 Index Pairs of a String

Given a text string and a list of words, find all index pairs [i, j] such that the substring text[i...j] is one of the words. Return pairs sorted by first index, then by second index.

⏱️ Time: O(n × m × w) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function indexPairs(text, words) {
  const result = [];
  
  // Check each position in text
  for (let i = 0; i < text.length; i++) {
    // Check each word
    for (const word of words) {
      // Check if word matches at position i
      if (text.substring(i, i + word.length) === word) {
        result.push([i, i + word.length - 1]);
      }
    }
  }
  
  // Sort by first index, then second index
  result.sort((a, b) => {
    if (a[0] !== b[0]) return a[0] - b[0];
    return a[1] - b[1];
  });
  
  return result;
}

📖 Algorithm Explanation

  • For each position i in the text, check if any word starts at that position.
  • Use substring comparison to check if text[i...i+word.length] equals the word.
  • When a match is found, record the pair [start_index, end_index].
  • Sort results by first index, then by second index.
