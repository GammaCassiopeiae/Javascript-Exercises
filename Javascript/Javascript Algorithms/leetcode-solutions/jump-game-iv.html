🦘 Jump Game IV

Given an array of integers, find the minimum number of steps to reach the last index. From index i, you can jump to: i+1, i-1, or any index j where arr[i] == arr[j] and i != j.

⏱️ Time: O(n) 💾 Space: O(n) 📊 Difficulty: Hard

💻 Solution Code

function minJumps(arr) {
  const n = arr.length;
  if (n === 1) return 0;
  
  // Build graph of same values
  const graph = new Map();
  for (let i = 0; i < n; i++) {
    if (!graph.has(arr[i])) graph.set(arr[i], []);
    graph.get(arr[i]).push(i);
  }
  
  const visited = new Set([0]);
  const queue = [0];
  let steps = 0;
  
  while (queue.length > 0) {
    const size = queue.length;
    
    for (let i = 0; i < size; i++) {
      const curr = queue.shift();
      if (curr === n - 1) return steps;
      
      // Try i+1, i-1, and same value indices
      const neighbors = [curr - 1, curr + 1, ...graph.get(arr[curr])];
      
      for (const next of neighbors) {
        if (next >= 0 && next < n && !visited.has(next)) {
          visited.add(next);
          queue.push(next);
        }
      }
      
      // Clear to avoid revisiting same values
      graph.delete(arr[curr]);
    }
    steps++;
  }
  
  return -1;
}

📖 Algorithm Explanation

  • Use BFS to find the shortest path (minimum steps).
  • Build a graph mapping each value to all its indices.
  • From each position, try jumping to i-1, i+1, or any same-value index.
  • After using same-value jumps, clear the entry to avoid redundant exploration.
