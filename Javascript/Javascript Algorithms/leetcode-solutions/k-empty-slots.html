🌸 K Empty Slots

You have n bulbs in a row numbered from 1 to n. Initially, all bulbs are turned off. On day i, bulb at position flowers[i] turns on. Find the earliest day such that there are two turned on bulbs with exactly k bulbs between them that are all off.

⏱️ Time: O(n) 💾 Space: O(n) 📊 Difficulty: Hard

💻 Solution Code

JavaScript 
function kEmptySlots(flowers, k) {
  const n = flowers.length;
  const days = new Array(n + 1);
  
  // days[pos] = day when bulb at pos turns on
  for (let i = 0; i < n; i++) {
    days[flowers[i]] = i + 1;
  }
  
  let left = 1, right = k + 2;
  let result = Infinity;
  
  for (let i = 1; right <= n; i++) {
    if (days[i] < days[left] || days[i] <= days[right]) {
      if (i === right) {
        result = Math.min(result, Math.max(days[left], days[right]));
      }
      left = i;
      right = i + k + 2;
    }
  }
  
  return result === Infinity ? -1 : result;
}

📖 Algorithm Explanation

  • Convert to days array: days[pos] = day bulb turns on.
  • Use sliding window of size k+2.
  • Check if all bulbs between left and right turn on later.
  • Track minimum day when valid configuration found.

📝 Example Walkthrough

Input: flowers = [1,3,2], k = 1

days array (1-indexed):
days[1] = 1 (bulb 1 on day 1)
days[2] = 3 (bulb 2 on day 3)
days[3] = 2 (bulb 3 on day 2)

Window [left=1, right=3]:
- Check if days[2] > max(days[1], days[3])
- days[2]=3 > max(1,2)=2 ✓

Valid! Day = max(1, 2) = 2

On day 2: bulbs 1 and 3 are on, bulb 2 is off.
Result: 2
