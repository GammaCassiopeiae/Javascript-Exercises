♞ Knight Dialer

A chess knight can move in an L-shape. Given a phone pad, place the knight on any digit and make n-1 hops. Return how many distinct numbers can be dialed. Return answer modulo 10^9 + 7.

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function knightDialer(n) {
  const MOD = 1e9 + 7;
  
  // Knight moves from each digit
  const moves = [
    [4, 6],      // 0
    [6, 8],      // 1
    [7, 9],      // 2
    [4, 8],      // 3
    [0, 3, 9],  // 4
    [],          // 5 (no moves)
    [0, 1, 7],  // 6
    [2, 6],      // 7
    [1, 3],      // 8
    [2, 4]       // 9
  ];
  
  // dp[digit] = count of numbers ending at digit
  let dp = new Array(10).fill(1);
  
  for (let hop = 1; hop < n; hop++) {
    const newDp = new Array(10).fill(0);
    for (let d = 0; d < 10; d++) {
      for (const next of moves[d]) {
        newDp[next] = (newDp[next] + dp[d]) % MOD;
      }
    }
    dp = newDp;
  }
  
  return dp.reduce((a, b) => (a + b) % MOD, 0);
}

📖 Algorithm Explanation

  • Precompute knight moves from each digit on the phone pad.
  • Use DP where dp[d] = count of numbers ending at digit d.
  • For each hop, update counts based on valid knight moves.
  • Sum all counts at the end for total distinct numbers.
