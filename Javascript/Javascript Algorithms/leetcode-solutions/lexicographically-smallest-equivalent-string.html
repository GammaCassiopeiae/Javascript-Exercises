🔤 Lexicographically Smallest Equivalent String

Given two strings s1 and s2 of the same length defining character equivalencies, and a base string baseStr, return the lexicographically smallest equivalent string. Characters in the same equivalence group can be swapped, so use the smallest character from each group.

⏱️ Time: O(n + m) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function smallestEquivalentString(s1, s2, baseStr) {
  // Union-Find with path compression
  const parent = new Array(26).fill(null).map((_, i) => i);
  
  function find(x) {
    if (parent[x] !== x) {
      parent[x] = find(parent[x]); // Path compression
    }
    return parent[x];
  }
  
  function union(x, y) {
    const rootX = find(x), rootY = find(y);
    if (rootX !== rootY) {
      // Always attach to smaller character
      parent[Math.max(rootX, rootY)] = Math.min(rootX, rootY);
    }
  }
  
  // Build equivalence groups
  for (let i = 0; i < s1.length; i++) {
    union(s1.charCodeAt(i) - 97, s2.charCodeAt(i) - 97);
  }
  
  // Transform baseStr using smallest equivalent
  return baseStr.split('').map(c => {
    const root = find(c.charCodeAt(0) - 97);
    return String.fromCharCode(root + 97);
  }).join('');
}

📖 Algorithm Explanation

  • Use Union-Find (Disjoint Set Union) to group equivalent characters.
  • When unioning, always attach to the smaller character (lexicographically).
  • Use path compression for efficient find operations.
  • For each character in baseStr, replace it with its root (smallest equivalent).

📝 Example Walkthrough

Input: s1 = "parker", s2 = "morris", baseStr = "parser"

Equivalencies:
p↔m, a↔o, r↔r, k↔r, e↔i, r↔s

Groups formed:
{a, m, o, p} → smallest: a
{e, i} → smallest: e
{k, r, s} → smallest: k

Transform "parser":
p → a (from {a,m,o,p})
a → a (from {a,m,o,p})
r → k (from {k,r,s})
s → k (from {k,r,s})
e → e (from {e,i})
r → k (from {k,r,s})

Result: "aakkek"
