🔗 Linked List Random Node

Given a singly linked list, return a random node's value from the linked list. Each node must have the same probability of being chosen. Follow-up: What if the linked list is extremely large and its length is unknown?

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
class Solution {
  constructor(head) {
    this.head = head;
  }

  getRandom() {
    // Reservoir sampling (k=1)
    let result = this.head.val;
    let current = this.head.next;
    let i = 2;
    
    while (current) {
      // Replace result with probability 1/i
      if (Math.random() < 1 / i) {
        result = current.val;
      }
      current = current.next;
      i++;
    }
    
    return result;
  }
}

📖 Algorithm Explanation

  • Use reservoir sampling algorithm for O(1) space.
  • Start with first node's value as result.
  • For each subsequent node i, replace result with probability 1/i.
  • This ensures each node has equal probability 1/n of being selected.
  • Works even when list length is unknown!

📝 Example Walkthrough

Input: [1, 2, 3, 4, 5]

Reservoir sampling process:
- Start: result = 1 (first node)
- Node 2 (i=2): replace with prob 1/2
- Node 3 (i=3): replace with prob 1/3
- Node 4 (i=4): replace with prob 1/4
- Node 5 (i=5): replace with prob 1/5

Each node has probability 1/5 of being selected!

Proof for node 3:
- Not replaced at i=2: prob 1/2
- Selected at i=3: prob 1/3
- Not replaced at i=4: prob 3/4
- Not replaced at i=5: prob 4/5
Total: 1/2 × 1/3 × 3/4 × 4/5 = 1/5 ✓
