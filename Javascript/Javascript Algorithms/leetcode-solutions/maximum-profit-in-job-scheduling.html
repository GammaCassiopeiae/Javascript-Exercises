💼 Maximum Profit in Job Scheduling

Given n jobs with start time, end time, and profit, find the maximum profit you can obtain by selecting non-overlapping jobs. Jobs are represented as [startTime, endTime, profit].

⏱️ Time: O(n log n) 💾 Space: O(n) 📊 Difficulty: Hard

💻 Solution Code

JavaScript 
function jobScheduling(startTime, endTime, profit) {
  const n = startTime.length;
  const jobs = startTime.map((s, i) => [s, endTime[i], profit[i]]);
  
  // Sort by end time
  jobs.sort((a, b) => a[1] - b[1]);
  
  // dp[i] = max profit considering jobs 0 to i
  const dp = [0];
  const endTimes = [0];
  
  for (const [start, end, p] of jobs) {
    // Binary search for latest non-overlapping job
    let lo = 0, hi = endTimes.length - 1;
    while (lo < hi) {
      const mid = Math.ceil((lo + hi) / 2);
      if (endTimes[mid] <= start) lo = mid;
      else hi = mid - 1;
    }
    
    // Max of: skip this job OR take it + best before
    const newProfit = Math.max(dp[dp.length - 1], dp[lo] + p);
    dp.push(newProfit);
    endTimes.push(end);
  }
  
  return dp[dp.length - 1];
}

📖 Algorithm Explanation

  • Sort jobs by end time for efficient DP.
  • Use DP where dp[i] = max profit using subset of first i jobs.
  • For each job, use binary search to find latest non-overlapping job.
  • Take max of: skipping current job OR taking it plus best profit before it starts.

📝 Example Walkthrough

Input: startTime = [1,2,4], endTime = [3,5,6], profit = [5,6,4]

Jobs sorted by end time:
[1,3,5], [2,5,6], [4,6,4]

DP calculation:
- Job [1,3,5]: Take it → profit = 5
  dp = [0, 5]
- Job [2,5,6]: Latest non-overlap ends at 1
  Take: dp[0]+6=6, Skip: 5 → max = 6
  dp = [0, 5, 6]
- Job [4,6,4]: Latest non-overlap ends at 3
  Take: dp[1]+4=9, Skip: 6 → max = 9
  dp = [0, 5, 6, 9]

Result: 9 (jobs [1,3,5] and [4,6,4])
