📊 Minimum Moves to Equal Array Elements

Given an array of integers, return the minimum number of moves required to make all array elements equal, where a move increments n-1 elements by 1.

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function minMoves(nums) {
  // Key insight: Incrementing n-1 elements by 1 is
  // equivalent to decrementing 1 element by 1
  
  // So we need to find how many decrements to make
  // all elements equal to the minimum
  
  const min = Math.min(...nums);
  let moves = 0;
  
  for (const num of nums) {
    moves += num - min;
  }
  
  return moves;
}

// Alternative one-liner:
// return nums.reduce((sum, n) => sum + n, 0) - 
//        Math.min(...nums) * nums.length;

📖 Algorithm Explanation

  • Key insight: Incrementing n-1 elements by 1 is mathematically equivalent to decrementing 1 element by 1.
  • So instead of bringing all elements up, think of bringing all elements down to the minimum.
  • For each element, the number of moves needed is (element - minimum).
  • Sum all these differences to get the total minimum moves.

📝 Example Walkthrough 

Input: [1, 2, 3]

Minimum element: 1

Moves needed:
- Element 1: 1 - 1 = 0 moves
- Element 2: 2 - 1 = 1 move
- Element 3: 3 - 1 = 2 moves

Total: 0 + 1 + 2 = 3 moves

Verification (increment n-1 approach):
[1,2,3] → [2,3,3] → [3,4,3] → [4,4,4]
           ↑          ↑          ↑
        inc 1,2    inc 1,3    inc 2,3
        
3 moves to make all equal!
