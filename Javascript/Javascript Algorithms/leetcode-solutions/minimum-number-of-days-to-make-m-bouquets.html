💐 Minimum Number of Days to Make m Bouquets

Given an array of bloom days for flowers, make m bouquets with k adjacent flowers each. Find the minimum number of days to wait to make all bouquets.

⏱️ Time: O(n × log(max(bloomDay))) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function minDays(bloomDay, m, k) {
  const n = bloomDay.length;
  
  // Check if it's possible
  if (n < m * k) return -1;
  
  // Binary search on the answer
  let left = Math.min(...bloomDay);
  let right = Math.max(...bloomDay);
  
  function canMakeBouquets(day) {
    let bouquets = 0;
    let flowers = 0;
    
    for (let bloom of bloomDay) {
      if (bloom <= day) {
        flowers++;
        if (flowers === k) {
          bouquets++;
          flowers = 0;
        }
      } else {
        flowers = 0;
      }
    }
    
    return bouquets >= m;
  }
  
  while (left < right) {
    const mid = Math.floor((left + right) / 2);
    if (canMakeBouquets(mid)) {
      right = mid;
    } else {
      left = mid + 1;
    }
  }
  
  return left;
}

📖 Algorithm Explanation

  • Use binary search on the number of days (the answer).
  • For each candidate day, check if we can make m bouquets.
  • To check, count consecutive bloomed flowers and form bouquets.
  • The minimum day where we can make all bouquets is the answer.
