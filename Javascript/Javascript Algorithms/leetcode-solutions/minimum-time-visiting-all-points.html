🎯 Minimum Time Visiting All Points

On a 2D plane, visit all points in the given order. In 1 second, you can move vertically, horizontally, or diagonally (√2 units). Return the minimum time to visit all points in order.

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function minTimeToVisitAllPoints(points) {
  let totalTime = 0;
  
  for (let i = 1; i < points.length; i++) {
    const [x1, y1] = points[i - 1];
    const [x2, y2] = points[i];
    
    // Chebyshev distance: max of horizontal and vertical
    const dx = Math.abs(x2 - x1);
    const dy = Math.abs(y2 - y1);
    
    // Diagonal movement covers both directions
    totalTime += Math.max(dx, dy);
  }
  
  return totalTime;
}

📖 Algorithm Explanation

  • With diagonal movement allowed, the time between two points is the Chebyshev distance.
  • Chebyshev distance = max(|x2-x1|, |y2-y1|).
  • Diagonal moves cover both x and y distance simultaneously.
  • Sum up the time for each consecutive pair of points.

📝 Example Walkthrough 

Input: points = [[1,1], [3,4], [-1,0]]

From (1,1) to (3,4):
- dx = |3-1| = 2
- dy = |4-1| = 3
- Time = max(2, 3) = 3 seconds

From (3,4) to (-1,0):
- dx = |-1-3| = 4
- dy = |0-4| = 4
- Time = max(4, 4) = 4 seconds

Total Time: 3 + 4 = 7 seconds
