🪨 Moving Stones Until Consecutive II

There are three stones at positions a, b, and c. Each turn, pick up a stone at an endpoint and move it to an unoccupied position between the endpoints. The game ends when stones are consecutive. Return [minimum_moves, maximum_moves].

⏱️ Time: O(1) 💾 Space: O(1) 📊 Difficulty: Medium

🎯 Input

📈 Result

✓
Moves [min, max]
[0, 0]

💻 Solution Code

JavaScript 
function numMovesStonesII(a, b, c) {
  const [x, y, z] = [a, b, c].sort((u, v) => u - v);
  
  // Already consecutive
  if (z - x === 2) return [0, 0];
  
  // Minimum moves
  let minMoves;
  if (y - x === 1 || z - y === 1) {
    // Two stones adjacent, need 1 move
    minMoves = 1;
  } else if (y - x === 2 || z - y === 2) {
    // Gap of 2, can fill in 1 move
    minMoves = 1;
  } else {
    minMoves = 2;
  }
  
  // Maximum moves: move endpoints inward
  const maxMoves = (y - x - 1) + (z - y - 1);
  
  return [minMoves, maxMoves];
}

📖 Algorithm Explanation

  • Sort positions to get x < y < z.
  • If already consecutive (z-x=2), 0 moves needed.
  • If two stones adjacent or gap of 2, min is 1.
  • Otherwise, min is 2 moves.
  • Max moves: sum of gaps between stones.

📝 Example Walkthrough

Input: a=1, b=2, c=5

Sorted: x=1, y=2, z=5

Minimum:
- y-x = 1 (adjacent)
- minMoves = 1
- Move stone at 5 to position 3

Maximum:
- Gap1: y-x-1 = 0
- Gap2: z-y-1 = 2
- maxMoves = 0 + 2 = 2

Result: [1, 2]
