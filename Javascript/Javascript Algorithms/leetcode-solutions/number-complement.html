🔢 Number Complement

The complement of an integer is obtained by flipping all the 0's to 1's and all the 1's to 0's in its binary representation. Given an integer, return its complement.

⏱️ Time: O(1) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function findComplement(num) {
  // Method 1: XOR with mask of all 1s
  if (num === 0) return 1;
  
  // Find mask with all 1s of same bit length
  let mask = num;
  mask |= mask >> 1;
  mask |= mask >> 2;
  mask |= mask >> 4;
  mask |= mask >> 8;
  mask |= mask >> 16;
  
  // XOR flips all bits within the mask
  return num ^ mask;
}

// Method 2: Simple bit flip
function findComplement2(num) {
  let result = 0, bit = 0;
  while (num > 0) {
    if ((num & 1) === 0) {
      result |= (1 << bit);
    }
    num >>= 1;
    bit++;
  }
  return result;
}

📖 Algorithm Explanation

  • Create a mask of all 1s with the same bit length as the number.
  • XOR the number with the mask to flip all bits.
  • The mask is created by propagating the highest set bit to all lower positions.
  • Alternative: iterate through bits and flip each one individually.
