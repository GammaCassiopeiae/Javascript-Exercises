🔐 Open the Lock

You have a lock with 4 circular wheels. Each wheel has digits 0-9. Given a target combination and a list of deadends, find the minimum number of turns to open the lock starting from "0000". Return -1 if impossible.

⏱️ Time: O(10^4) 💾 Space: O(10^4) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function openLock(deadends, target) {
  const deadSet = new Set(deadends);
  const visited = new Set();
  const queue = ['0000'];
  let turns = 0;

  if (deadSet.has('0000')) return -1;
  visited.add('0000');

  while (queue.length > 0) {
    const size = queue.length;
    
    for (let i = 0; i < size; i++) {
      const curr = queue.shift();
      if (curr === target) return turns;

      for (let j = 0; j < 4; j++) {
        for (const delta of [-1, 1]) {
          const digit = (parseInt(curr[j]) + delta + 10) % 10;
          const next = curr.slice(0, j) + digit + curr.slice(j + 1);
          
          if (!visited.has(next) && !deadSet.has(next)) {
            visited.add(next);
            queue.push(next);
          }
        }
      }
    }
    turns++;
  }

  return -1;
}

📖 Algorithm Explanation

  • Use BFS to find the shortest path from "0000" to target.
  • Each state is a 4-digit combination. From each state, generate 8 neighbors (4 wheels × 2 directions).
  • Use a set to track visited states and deadends to avoid revisiting.
  • The first time we reach target, we have the minimum turns.
