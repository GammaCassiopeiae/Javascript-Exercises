🎨 Paint House

There are n houses in a row, each can be painted red, blue, or green. The cost of painting each house with a certain color is different. Find the minimum cost to paint all houses such that no two adjacent houses have the same color.

💻 Solution Code

JavaScript 
function minCost(costs) {
  if (!costs.length) return 0;
  
  // dp[r], dp[g], dp[b] = min cost ending with that color
  let dpR = costs[0][0];
  let dpG = costs[0][1];
  let dpB = costs[0][2];
  
  for (let i = 1; i < costs.length; i++) {
    const newR = costs[i][0] + Math.min(dpG, dpB);
    const newG = costs[i][1] + Math.min(dpR, dpB);
    const newB = costs[i][2] + Math.min(dpR, dpG);
    
    dpR = newR;
    dpG = newG;
    dpB = newB;
  }
  
  return Math.min(dpR, dpG, dpB);
}

📖 Algorithm Explanation

  • Use DP where dp[color] = min cost to paint houses ending with that color.
  • For each house, new cost = current cost + min of other two colors from previous house.
  • This ensures no two adjacent houses have the same color.
  • Return minimum of all three final costs.

📝 Example Walkthrough

Input: costs = [[17,2,17],[16,16,5],[14,3,19]]
       (R:G:B costs for each house)

House 0: dp = [17, 2, 17]

House 1:
- Red: 16 + min(2, 17) = 18
- Green: 16 + min(17, 17) = 33
- Blue: 5 + min(17, 2) = 7
dp = [18, 33, 7]

House 2:
- Red: 14 + min(33, 7) = 21
- Green: 3 + min(18, 7) = 10
- Blue: 19 + min(18, 33) = 37
dp = [21, 10, 37]

Min cost: min(21, 10, 37) = 10

Optimal: House0=Green(2), House1=Blue(5), House2=Green(3)
Total: 2 + 5 + 3 = 10
