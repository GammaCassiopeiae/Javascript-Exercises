⚖️ Partition Equal Subset Sum

Given an integer array nums, return true if you can partition the array into two subsets such that the sum of the elements in both subsets is equal, or false otherwise.

⏱️ Time: O(n × sum) 💾 Space: O(sum) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function canPartition(nums) {
  const total = nums.reduce((a, b) => a + b, 0);
  
  // If sum is odd, can't partition equally
  if (total % 2 !== 0) return false;
  
  const target = total / 2;
  const dp = new Set([0]);
  
  for (const num of nums) {
    const newSums = new Set();
    for (const sum of dp) {
      if (sum + num === target) return true;
      if (sum + num < target) {
        newSums.add(sum + num);
      }
    }
    for (const s of newSums) {
      dp.add(s);
    }
  }
  
  return dp.has(target);
}

📖 Algorithm Explanation

  • If total sum is odd, partition is impossible.
  • Target sum for each subset is total/2.
  • Use DP/set to track all achievable sums.
  • For each number, add it to all existing sums.
  • If target is achievable, return true.
