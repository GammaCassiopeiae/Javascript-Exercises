Positions of Large Groups

LeetCode Problem - String Group Detection

Problem Description

In a string s of lowercase letters, consecutive characters form a group. A group is "large" if it has 3 or more characters. Return the intervals of every large group sorted by start index.

JavaScript Solution

function largeGroupPositions(s) {
    const result = [];
    let start = 0;
    
    for (let i = 0; i < s.length; i++) {
        // Check if we reached the end of a group
        if (i === s.length - 1 || s[i] !== s[i + 1]) {
            // If group has 3 or more characters, add to result
            if (i - start + 1 >= 3) {
                result.push([start, i]);
            }
            start = i + 1;
        }
    }
    
    return result;
}

// Usage Example:
const s = "abbxxxxzzy";
console.log(largeGroupPositions(s)); // [[3, 6]] for "xxxx"
