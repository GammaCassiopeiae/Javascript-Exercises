🔢 Prime Palindrome

Find the smallest prime palindrome greater than or equal to n. A prime palindrome is a number that is both prime (only divisible by 1 and itself) and a palindrome (reads the same forwards and backwards).

⏱️ Time: O(√n × palindromes) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function primePalindrome(n) {
  // Helper: check if number is prime
  function isPrime(num) {
    if (num < 2) return false;
    if (num === 2) return true;
    if (num % 2 === 0) return false;
    for (let i = 3; i * i <= num; i += 2) {
      if (num % i === 0) return false;
    }
    return true;
  }

  // Helper: check if palindrome
  function isPalindrome(num) {
    const str = num.toString();
    return str === str.split('').reverse().join('');
  }

  // Optimization: skip even-digit palindromes > 11
  // (they're all divisible by 11)
  if (n >= 8 && n <= 11) return 11;
  if (n > 1e7 && n < 1e8) n = 1e8;

  for (let i = n; ; i++) {
    if (isPalindrome(i) && isPrime(i)) {
      return i;
    }
  }
}

📖 Algorithm Explanation

  • Check each number starting from n until we find a prime palindrome.
  • isPrime: Check divisibility up to √num (skip even numbers after 2).
  • isPalindrome: Convert to string and compare with reversed version.
  • Optimization: All even-digit palindromes > 11 are divisible by 11, so skip to next odd digit range.
