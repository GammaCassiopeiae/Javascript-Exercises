🔑 Queries on a Permutation With Key

Given an array of queries and a value m, process each query by finding the position of the queried element in a permutation P=[1,2,3,...,m], then moving that element to the front. Return the positions before each move.

⏱️ Time: O(n*m) 💾 Space: O(m) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function processQueries(queries, m) {
  // Initialize permutation P = [1, 2, 3, ..., m]
  const P = Array.from({ length: m }, (_, i) => i + 1);
  const result = [];

  for (const query of queries) {
    // Find position of query element in P
    const pos = P.indexOf(query);
    result.push(pos);

    // Move element to front
    P.splice(pos, 1);  // Remove from current position
    P.unshift(query);     // Add to front
  }

  return result;
}

📖 Algorithm Explanation

  • Start with a permutation P = [1, 2, 3, ..., m].
  • For each query, find the index of the queried element in P.
  • Record this index as the answer for this query.
  • Move the queried element to the front of P (remove and unshift).
