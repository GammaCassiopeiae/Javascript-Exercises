🎲 Random Flip Matrix

Design an algorithm to randomly flip a 0 to 1 in an m x n binary matrix (all initialized to 0). Each 0 should have equal probability of being flipped. Optimize to minimize calls to the random API and optimize time/space complexity.

⏱️ Time: O(1) 💾 Space: O(k) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
class Solution {
  constructor(m, n) {
    this.m = m;
    this.n = n;
    this.total = m * n;
    this.mapped = new Map(); // Maps used indices to available ones
  }

  flip() {
    // Pick random index from remaining
    const randIdx = Math.floor(Math.random() * this.total);
    this.total--;
    
    // Get actual index (handle mapping)
    const actualIdx = this.mapped.get(randIdx) ?? randIdx;
    
    // Map the picked index to the last available one
    const lastIdx = this.mapped.get(this.total) ?? this.total;
    this.mapped.set(randIdx, lastIdx);
    
    return [Math.floor(actualIdx / this.n), actualIdx % this.n];
  }

  reset() {
    this.total = this.m * this.n;
    this.mapped.clear();
  }
}

📖 Algorithm Explanation

  • Use a hash map to track which indices have been swapped.
  • Pick a random index from 0 to total-1 (remaining cells).
  • If the index was previously mapped, use the mapped value.
  • Swap the picked index with the last available index (using map).
  • This ensures O(1) time and O(k) space where k is number of flips.

📝 Example Walkthrough

Matrix: 3x3 (9 cells, indices 0-8)

Initial: total = 9, mapped = {}

Flip 1: randIdx = 5
  actualIdx = 5 → [1, 2]
  Map 5 → 8 (swap with last)
  total = 8

Flip 2: randIdx = 2
  actualIdx = 2 → [0, 2]
  Map 2 → 7 (swap with last)
  total = 7

Flip 3: randIdx = 5
  actualIdx = mapped[5] = 8 → [2, 2]
  Map 5 → 6 (swap with last)
  total = 6

Each flip has equal probability among remaining cells!
