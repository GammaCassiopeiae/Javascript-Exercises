🌳 Range Sum of BST

Given the root node of a binary search tree and two integers low and high, return the sum of values of all nodes with a value in the inclusive range [low, high].

⏱️ Time: O(n) 💾 Space: O(h) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function rangeSumBST(root, low, high) {
  if (!root) return 0;
  
  let sum = 0;
  
  // Use BST property to prune search
  if (root.val >= low) {
    sum += rangeSumBST(root.left, low, high);
  }
  
  // Add current node if in range
  if (root.val >= low && root.val <= high) {
    sum += root.val;
  }
  
  if (root.val <= high) {
    sum += rangeSumBST(root.right, low, high);
  }
  
  return sum;
}

📖 Algorithm Explanation

  • Use DFS to traverse the BST.
  • Leverage BST property: if node.val < low, skip left subtree.
  • If node.val > high, skip right subtree.
  • Add node value to sum if it's within [low, high].
