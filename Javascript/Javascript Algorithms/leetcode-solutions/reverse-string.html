🔄 Reverse String

Write a function that reverses a string. The input string is given as an array of characters. You must do this by modifying the input array in-place with O(1) extra memory.

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

JavaScript 
function reverseString(s) {
  let left = 0;
  let right = s.length - 1;

  // Two-pointer approach
  while (left < right) {
    // Swap characters at left and right pointers
    const temp = s[left];
    s[left] = s[right];
    s[right] = temp;

    // Move pointers toward center
    left++;
    right--;
  }

  return s;
}

📖 Algorithm Explanation

  • Use two pointers: one at the start (left) and one at the end (right) of the array.
  • Swap the characters at the left and right pointers.
  • Move the left pointer forward and the right pointer backward.
  • Continue until the pointers meet in the middle.
