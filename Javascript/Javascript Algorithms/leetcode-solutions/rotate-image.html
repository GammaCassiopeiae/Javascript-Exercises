🔄 Rotate Image

Given an n × n 2D matrix representing an image, rotate the image by 90 degrees clockwise. You must rotate the image in-place (modify the input matrix directly).

⏱️ Time: O(n²) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function rotate(matrix) {
  const n = matrix.length;
  
  // Step 1: Transpose (swap across diagonal)
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      [matrix[i][j], matrix[j][i]] = [matrix[j][i], matrix[i][j]];
    }
  }
  
  // Step 2: Reverse each row
  for (let i = 0; i < n; i++) {
    let left = 0, right = n - 1;
    while (left < right) {
      [matrix[i][left], matrix[i][right]] = [matrix[i][right], matrix[i][left]];
      left++;
      right--;
    }
  }
  
  return matrix;
}

📖 Algorithm Explanation

  • 90° clockwise rotation = Transpose + Reverse each row.
  • Transpose: Swap matrix[i][j] with matrix[j][i] for all i < j.
  • Reverse each row: Swap elements from left and right ends moving inward.
  • Both operations are done in-place with O(1) extra space.
