🌳 Smallest Subtree with all the Deepest Nodes

Given the root of a binary tree, return the smallest subtree that contains all the deepest nodes. A subtree is defined as a node plus all its descendants.

⏱️ Time: O(n) 💾 Space: O(h) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function subtreeWithAllDeepest(root) {
  function dfs(node) {
    if (!node) return { depth: 0, node: null };
    
    const left = dfs(node.left);
    const right = dfs(node.right);
    
    if (left.depth > right.depth) {
      return { depth: left.depth + 1, node: left.node };
    }
    if (right.depth > left.depth) {
      return { depth: right.depth + 1, node: right.node };
    }
    
    // Both subtrees have deepest nodes
    return { depth: left.depth + 1, node };
  }
  
  return dfs(root).node;
}

📖 Algorithm Explanation

  • Use DFS to calculate depth of each subtree.
  • If left subtree is deeper, the answer is in the left subtree.
  • If right subtree is deeper, the answer is in the right subtree.
  • If both have equal depth, current node is the LCA of deepest nodes.

📝 Example Walkthrough

Input: [3,5,1,6,2,0,8,null,null,7,4]

Tree structure:
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4

Deepest nodes: 6, 7, 4, 0, 8 (depth 3)
But 7 and 4 are deepest in their branch

Node 5's subtree contains 7 and 4 (deepest)
Node 1's subtree contains 0 and 8 (same depth)

Since both branches have nodes at depth 3,
the answer is root node 3.

Result: 3
