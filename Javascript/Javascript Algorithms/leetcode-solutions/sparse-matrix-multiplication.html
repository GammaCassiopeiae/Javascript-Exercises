🔢 Sparse Matrix Multiplication

Given two sparse matrices A and B, return the result of AB. A sparse matrix is a matrix in which most of the elements are zero. The algorithm optimizes by skipping zero elements.

⏱️ Time: O(m*n*p) worst case, better for sparse 💾 Space: O(1) excluding result 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function multiply(mat1, mat2) {
  const m = mat1.length;
  const n = mat1[0].length;
  const p = mat2[0].length;

  // Initialize result matrix with zeros
  const result = Array.from({ length: m }, () => Array(p).fill(0));

  // Optimized for sparse matrices
  for (let i = 0; i < m; i++) {
    for (let k = 0; k < n; k++) {
      // Skip if mat1[i][k] is zero (sparse optimization)
      if (mat1[i][k] === 0) continue;

      for (let j = 0; j < p; j++) {
        // Skip if mat2[k][j] is zero
        if (mat2[k][j] !== 0) {
          result[i][j] += mat1[i][k] * mat2[k][j];
        }
      }
    }
  }

  return result;
}

📖 Algorithm Explanation

  • Matrix multiplication: result[i][j] = Σ(mat1[i][k] * mat2[k][k]) for all k.
  • For sparse matrices, we optimize by skipping zero elements in mat1.
  • We iterate through mat1's non-zero elements and only multiply with non-zero elements in mat2.
  • This significantly reduces computation when matrices have many zeros.
