📜 String Compression II

Run-length encoding replaces consecutive identical characters with the character followed by the count. Given a string s and an integer k, delete at most k characters to minimize the length of the run-length encoded string.

⏱️ Time: O(n² × k) 💾 Space: O(n × k) 📊 Difficulty: Hard

💻 Solution Code

function getLengthOfOptimalCompression(s, k) {
  const n = s.length;
  const memo = new Map();

  function dp(i, deletionsLeft) {
    if (deletionsLeft < 0) return Infinity;
    if (i >= n) return 0;

    const key = `${i},${deletionsLeft}`;
    if (memo.has(key)) return memo.get(key);

    // Option 1: Delete current character
    let result = dp(i + 1, deletionsLeft - 1);

    // Option 2: Keep current character
    let count = 0, deletions = 0;
    for (let j = i; j < n && deletions + deletionsLeft <= k; j++) {
      if (s[j] === s[i]) count++;
      else deletions++;

      if (deletions + deletionsLeft <= k) {
        const len = 1 + (count >= 100 ? 3 : count >= 10 ? 2 : count >= 2 ? 1 : 0);
        result = Math.min(result, len + dp(j + 1, deletionsLeft - deletions));
      }
    }

    memo.set(key, result);
    return result;
  }

  return dp(0, k);
}

📖 Algorithm Explanation

  • Uses dynamic programming with memoization to explore all possibilities.
  • At each position, decide whether to delete the character or keep it.
  • When keeping, try grouping consecutive same characters together.
  • The encoded length depends on count: 1 char for count 1, +1 for 2-9, +1 for 10-99, +1 for 100+.
