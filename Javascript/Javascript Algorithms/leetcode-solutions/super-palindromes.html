✨ Super Palindromes

A super palindrome is a positive integer that is a palindrome and whose square root is also a palindrome. Count super palindromes in the range [left, right] inclusive.

⏱️ Time: O(√right × log(right)) 💾 Space: O(1) 📊 Difficulty: Hard

💻 Solution Code

JavaScript 
function superpalindromesInRange(left, right) {
  const L = BigInt(left);
  const R = BigInt(right);
  
  function isPalindrome(s) {
    return s === s.split('').reverse().join('');
  }
  
  let count = 0;
  
  // Generate palindromes by constructing the first half
  // For odd length palindromes
  for (let i = 1; i < 100000; i++) {
    const s = i.toString();
    // Odd length palindrome
    const oddPalin = s + s.slice(0, -1).split('').reverse().join('');
    const oddNum = BigInt(oddPalin);
    const oddSq = oddNum * oddNum;
    if (oddSq >= L && oddSq <= R && isPalindrome(oddSq.toString())) {
      count++;
    }
    
    // Even length palindrome
    const evenPalin = s + s.split('').reverse().join('');
    const evenNum = BigInt(evenPalin);
    const evenSq = evenNum * evenNum;
    if (evenSq >= L && evenSq <= R && isPalindrome(evenSq.toString())) {
      count++;
    }
  }
  
  return count;
}

📖 Algorithm Explanation

  • Generate palindromes by constructing them from their first half.
  • For each palindrome, square it and check if the result is also a palindrome.
  • Count those whose squares fall within the given range.
  • Use BigInt for handling large numbers accurately.
