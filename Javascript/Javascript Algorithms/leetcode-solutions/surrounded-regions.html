⭕ Surrounded Regions

Given an m x n matrix board containing 'X' and 'O', capture all regions surrounded by 'X'. A region is captured by flipping all 'O's into 'X's in that surrounded region. Note: 'O's on the border or connected to border 'O's are not captured.

⏱️ Time: O(m × n) 💾 Space: O(m × n) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function solve(board) {
  if (!board.length) return;
  const m = board.length, n = board[0].length;
  
  // DFS to mark border-connected 'O's as 'T'
  function dfs(i, j) {
    if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] !== 'O') return;
    board[i][j] = 'T';
    dfs(i - 1, j); dfs(i + 1, j);
    dfs(i, j - 1); dfs(i, j + 1);
  }
  
  // Mark border 'O's and their connected regions
  for (let i = 0; i < m; i++) {
    dfs(i, 0); dfs(i, n - 1);
  }
  for (let j = 0; j < n; j++) {
    dfs(0, j); dfs(m - 1, j);
  }
  
  // Flip remaining 'O's to 'X', restore 'T' to 'O'
  for (let i = 0; i < m; i++) {
    for (let j = 0; j < n; j++) {
      if (board[i][j] === 'O') board[i][j] = 'X';
      else if (board[i][j] === 'T') board[i][j] = 'O';
    }
  }
}

📖 Algorithm Explanation

  • Instead of finding surrounded regions, find regions NOT surrounded (connected to border).
  • Use DFS from all border 'O's to mark connected 'O's as temporary 'T'.
  • After marking, flip all remaining 'O's to 'X' (these are surrounded).
  • Restore 'T' back to 'O' (these are border-connected, not captured).
