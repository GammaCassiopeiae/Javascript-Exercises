🔀 Swap For Longest Repeated Character Substring

Given a string text, swap two characters to maximize the length of the longest substring of repeated characters. Return the length of the longest such substring.

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function maxRepOpt1(text) {
  const n = text.length;
  const count = new Map();
  
  // Count frequency of each character
  for (let char of text) {
    count.set(char, (count.get(char) || 0) + 1);
  }
  
  let maxLen = 0;
  
  // For each character, find the longest substring
  for (let char of count.keys()) {
    let i = 0;
    while (i < n) {
      // Skip characters that don't match
      while (i < n && text[i] !== char) i++;
      if (i >= n) break;
      
      // Count consecutive characters
      let j = i;
      while (j < n && text[j] === char) j++;
      let len1 = j - i;
      
      // Try to extend by skipping one different character
      let k = j + 1;
      while (k < n && text[k] === char) k++;
      let len2 = k - j - 1;
      
      // Can we swap to connect them?
      let combined = len1 + len2;
      if (j < n && count.get(char) > combined) {
        combined++; // Can swap one more character
      }
      
      maxLen = Math.max(maxLen, Math.min(combined, count.get(char)));
      i = j;
    }
  }
  
  return maxLen;
}

📖 Algorithm Explanation

  • Count the frequency of each character in the string.
  • For each character, find all consecutive groups.
  • Try to merge two groups by swapping one character in between.
  • The result is limited by the total count of that character.

📝 Example Walkthrough

Input: text = "ababa"

Character counts: a=3, b=2

For 'a':
- Group 1: positions 0-2 (length 1)
- Group 2: positions 3-4 (length 2)
- Can swap 'b' at position 2 to connect
- Result: "aaaba" → longest 'a' substring = 3

Maximum length = 3
