🔢 Total Hamming Distance

The Hamming distance between two integers is the number of positions at which the corresponding bits are different. Given an array of integers, calculate the total Hamming distance between all pairs of numbers.

⏱️ Time: O(n) 💾 Space: O(1) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function totalHammingDistance(nums) {
  let totalDistance = 0;
  const n = nums.length;
  
  // For each bit position (0-31)
  for (let bit = 0; bit < 32; bit++) {
    let countOnes = 0;
    
    // Count numbers with this bit set
    for (const num of nums) {
      countOnes += (num >> bit) & 1;
    }
    
    // Count numbers with this bit unset
    let countZeros = n - countOnes;
    
    // Add contribution to total distance
    totalDistance += countOnes * countZeros;
  }
  
  return totalDistance;
}

📖 Algorithm Explanation

  • Instead of comparing all pairs (O(n²)), we count bit by bit for O(n) efficiency.
  • For each bit position, count how many numbers have a 1 and how many have a 0.
  • The contribution to total distance for each bit position is: countOnes × countZeros.
  • Sum up contributions from all 32 bit positions to get the final answer.

📝 Example Walkthrough 

Input: [4, 14, 2]

Binary representations:
4  → 0100
14 → 1110
2  → 0010

Pairwise distances:
HD(4, 14) = 2 (bits differ at positions 0 and 3)
HD(4, 2)  = 1 (bit differs at position 2)
HD(14, 2) = 1 (bit differs at position 1)

Total = 2 + 1 + 1 = 6
