🌳 Two Sum BSTs

Given the roots of two binary search trees, return true if and only if there is a node in the first tree and a node in the second tree whose values sum up to a given integer target.

⏱️ Time: O(m + n) 💾 Space: O(m + n) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function twoSumBSTs(root1, root2, target) {
  // Get all values from tree1 into a set
  const values1 = new Set();
  function collect(node) {
    if (!node) return;
    values1.add(node.val);
    collect(node.left);
    collect(node.right);
  }
  collect(root1);
  
  // Check if complement exists in tree2
  function check(node) {
    if (!node) return false;
    if (values1.has(target - node.val)) return true;
    return check(node.left) || check(node.right);
  }
  
  return check(root2);
}

📖 Algorithm Explanation

  • Collect all values from the first tree into a hash set.
  • For each node in the second tree, check if (target - node.val) exists in the set.
  • If found, return true. If we traverse all nodes without finding, return false.
  • Time: O(m + n), Space: O(m) for the set.

📝 Example Walkthrough

Input: root1 = [2,1,4], root2 = [1,0,3], target = 5

Tree 1 values: {1, 2, 4}
Tree 2 values: {0, 1, 3}

Check each value in tree2:
- 0: need 5-0=5, not in tree1
- 1: need 5-1=4, FOUND in tree1! ✓

Result: true
(Pair: 4 from tree1 + 1 from tree2 = 5)
