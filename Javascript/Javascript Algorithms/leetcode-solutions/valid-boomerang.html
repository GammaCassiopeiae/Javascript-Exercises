🎯 Valid Boomerang

Given an array points where points[i] = [xi, yi] represents three points on the X-Y plane, determine if they form a boomerang. A boomerang is a set of three points that are all distinct and not in a straight line.

⏱️ Time: O(1) 💾 Space: O(1) 📊 Difficulty: Easy

💻 Solution Code

function isBoomerang(points) {
  const [p1, p2, p3] = points;
  
  // Check if all points are distinct
  if ((p1[0] === p2[0] && p1[1] === p2[1]) ||
      (p1[0] === p3[0] && p1[1] === p3[1]) ||
      (p2[0] === p3[0] && p2[1] === p3[1])) {
    return false;
  }
  
  // Use cross product to check if collinear
  // (x2-x1)(y3-y1) - (y2-y1)(x3-x1) should not be 0
  const dx1 = p2[0] - p1[0];
  const dy1 = p2[1] - p1[1];
  const dx2 = p3[0] - p1[0];
  const dy2 = p3[1] - p1[1];
  
  return dx1 * dy2 !== dx2 * dy1;
}

📖 Algorithm Explanation

  • First check if all three points are distinct (no duplicates).
  • Use cross product to determine if points are collinear.
  • Cross product formula: (x2-x1)(y3-y1) - (y2-y1)(x3-x1).
  • If cross product is 0, points are on the same line (not a boomerang).

📝 Example Walkthrough

Input: [[1,1],[2,3],[3,2]]

Points: P1(1,1), P2(2,3), P3(3,2)

Check distinct: All different ✓

Cross product:
dx1 = 2-1 = 1, dy1 = 3-1 = 2
dx2 = 3-1 = 2, dy2 = 2-1 = 1

dx1 * dy2 = 1 * 1 = 1
dx2 * dy1 = 2 * 2 = 4

1 ≠ 4, so NOT collinear ✓

Result: true (valid boomerang)
