🤖 Walking Robot Simulation

A robot starts at (0, 0) facing north. Commands: -2 (turn left), -1 (turn right), 1-9 (move forward). Obstacles block movement. Return the maximum Euclidean distance squared from origin.

⏱️ Time: O(n + m) 💾 Space: O(m) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function robotSim(commands, obstacles) {
  // Directions: North, East, South, West
  const directions = [[0, 1], [1, 0], [0, -1], [-1, 0]];
  let dir = 0; // 0=N, 1=E, 2=S, 3=W
  let x = 0, y = 0;
  let maxDistSq = 0;

  // Store obstacles in a Set for O(1) lookup
  const obstacleSet = new Set(obstacles.map(o => o.join(",")));

  for (const cmd of commands) {
    if (cmd === -2) {
      // Turn left
      dir = (dir + 3) % 4;
    } else if (cmd === -1) {
      // Turn right
      dir = (dir + 1) % 4;
    } else {
      // Move forward
      for (let i = 0; i < cmd; i++) {
        const nx = x + directions[dir][0];
        const ny = y + directions[dir][1];
        if (!obstacleSet.has(`${nx},${ny}`)) {
          x = nx;
          y = ny;
          maxDistSq = Math.max(maxDistSq, x * x + y * y);
        }
      }
    }
  }

  return maxDistSq;
}

📖 Algorithm Explanation

  • Track robot position (x, y) and direction (0=N, 1=E, 2=S, 3=W).
  • Use a Set for O(1) obstacle lookup using "x,y" string keys.
  • For turn commands, update direction index (left: +3, right: +1, mod 4).
  • For move commands, step one unit at a time, checking for obstacles.

Input: commands = [4,-1,4,-2,4], obstacles = [[2,4]]

Command 4 (move 4 North):
(0,0) → (0,1) → (0,2) → (0,3) → (0,4)

(0,4) → (1,4) → STOP at (1,4)

maxDist = max(16, 1² + 4²) = 17

Now facing North

Command 4 (move 4 North):
(1,4) → (1,5)
maxDist = max(17, 1² + 5²) = 26

Final Answer: 26
