⚡ Zigzag Conversion

The string "PAYPALISHIRING" is written in a zigzag pattern on a given number of rows and then read line by line. Given a string and number of rows, return the converted string.

⏱️ Time: O(n) 💾 Space: O(n) 📊 Difficulty: Medium

💻 Solution Code

JavaScript 
function convert(s, numRows) {
  if (numRows === 1 || numRows >= s.length) return s;
  
  const rows = new Array(numRows).fill('');
  let currRow = 0;
  let goingDown = false;
  
  for (const char of s) {
    rows[currRow] += char;
    
    // Change direction at top or bottom
    if (currRow === 0 || currRow === numRows - 1) {
      goingDown = !goingDown;
    }
    
    currRow += goingDown ? 1 : -1;
  }
  
  return rows.join('');
}

📖 Algorithm Explanation

  • Create an array of strings, one for each row.
  • Iterate through the string, placing each character in the current row.
  • Change direction when reaching top or bottom row.
  • Concatenate all rows to get the final result.
