Binary Tree Inorder Traversal

Easy
TreeDFSStack

Problem Description

Return the inorder traversal of a binary tree.

Example 1:

Input: root = [1,null,2,3]
Output: [1,3,2]

Constraints:

  • The number of nodes is in the range [0, 100]

Solution

Iterative Solution

Optimal approach for solving Binary Tree Inorder Traversal.

function inorderTraversal(root) {
  const result = [];
  const stack = [];
  let current = root;
  while (current || stack.length > 0) {
    while (current) {
      stack.push(current);
      current = current.left;
    }
    current = stack.pop();
    result.push(current.val);
    current = current.right;
  }
  return result;
}

Complexity Analysis:

  • Time: O(n)
  • Space: O(n)
