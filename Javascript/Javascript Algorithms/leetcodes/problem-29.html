Jump Game

Medium
ArrayDPGreedy

Problem Description

Determine if you can reach the last index starting from the first index.

Example 1:

Input: nums = [2,3,1,1,4]
Output: true
Explanation: Jump 1 step, then 3 steps

Constraints:

  • 1 <= nums.length <= 10^4

Solution

Greedy Solution

Optimal approach for solving Jump Game.

function canJump(nums) {
  let maxReach = 0;
  for (let i = 0; i < nums.length; i++) {
    if (i > maxReach) return false;
    maxReach = Math.max(maxReach, i + nums[i]);
  }
  return true;
}

Complexity Analysis:

  • Time: O(n)
  • Space: O(1)
