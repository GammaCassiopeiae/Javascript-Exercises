Word Search

Medium
ArrayBacktrackingMatrix

Problem Description

Determine if a word exists in a 2D grid of characters.

Example 1:

Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
Output: true

Constraints:

  • 1 <= m, n <= 6

Solution

Backtracking DFS Solution

Optimal approach for solving Word Search.

function exist(board, word) {
  const rows = board.length, cols = board[0].length;
  function dfs(row, col, index) {
    if (index === word.length) return true;
    if (row < 0 || row >= rows || col < 0 || col >= cols || board[row][col] !== word[index]) return false;
    const temp = board[row][col];
    board[row][col] = '#';
    const found = dfs(row+1,col,index+1) || dfs(row-1,col,index+1) || dfs(row,col+1,index+1) || dfs(row,col-1,index+1);
    board[row][col] = temp;
    return found;
  }
  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      if (dfs(i, j, 0)) return true;
    }
  }
  return false;
}

Complexity Analysis:

  • Time: O(m*n*4^L)
  • Space: O(L)
