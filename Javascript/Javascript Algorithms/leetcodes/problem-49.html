Find the Duplicate Number

Medium
ArrayTwo PointersBinary Search

Problem Description

Find the duplicate number in an array of n+1 integers where each is in range [1, n].

Example 1:

Input: nums = [1,3,4,2,2]
Output: 2

Constraints:

  • There is only one duplicate number

Solution

Floyd's Cycle Detection Solution

Optimal approach for solving Find the Duplicate Number.

function findDuplicate(nums) {
  let slow = nums[0], fast = nums[0];
  do { slow = nums[slow]; fast = nums[nums[fast]]; } while (slow !== fast);
  slow = nums[0];
  while (slow !== fast) { slow = nums[slow]; fast = nums[fast]; }
  return slow;
}

Complexity Analysis:

  • Time: O(n)
  • Space: O(1)
