Rotate Array

Medium
ArrayTwo Pointers

Problem Description

Rotate an array to the right by k steps.

Example 1:

Input: nums = [1,2,3,4,5,6,7], k = 3
Output: [5,6,7,1,2,3,4]

Constraints:

  • 1 <= nums.length <= 10^5

Solution

Reverse Solution

Optimal approach for solving Rotate Array.

function rotate(nums, k) {
  k %= nums.length;
  function reverse(arr, start, end) {
    while (start < end) {
      [arr[start], arr[end]] = [arr[end], arr[start]];
      start++; end--;
    }
  }
  reverse(nums, 0, nums.length - 1);
  reverse(nums, 0, k - 1);
  reverse(nums, k, nums.length - 1);
}

Complexity Analysis:

  • Time: O(n)
  • Space: O(1)
