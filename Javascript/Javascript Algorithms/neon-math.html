Pascal's Triangle

Binomial Coefficients

Each entry is C(n, k) = n! / (k!(n-k)!). The sum of row n equals 2n. Edge cells are always 1; inner cells are the sum of the two parents above.

C(n, k) = n! / (k! · (n − k)!)

Leibniz Harmonic Series

Alternating · π/4

The Leibniz series sums alternating reciprocals of odd numbers. Its partial sums oscillate around and converge to π/4. Shown as signed rectangles whose total area approaches the limit.

π/4 = 1 − 1/3 + 1/5 − 1/7 + 1/9 − ...

Stirling Numbers (2nd Kind)

S(n, k) · Set Partitions

S(n, k) counts the ways to partition a set of n labeled elements into k non-empty unlabeled subsets. Recurrence: S(n, k) = k·S(n−1, k) + S(n−1, k−1).

S(n, k) = k · S(n−1, k) + S(n−1, k−1)
n 8

Bell Numbers

B(n) = Σ S(n, k)

The Bell number B(n) counts all partitions of an n-element set — the row sum of the Stirling triangle. Alternatively via the recurrence: B(n+1) = Σ C(n, k) · B(k).

B(n+1) = Σk=0..n C(n, k) · B(k)

Fibonacci Spiral

F(n) = F(n−1) + F(n−2)

Each Fibonacci number is the sum of the two before it. Squares of side F(n) tile a rectangle whose aspect ratio converges to the golden ratio φ ≈ 1.618. A logarithmic spiral is inscribed.
