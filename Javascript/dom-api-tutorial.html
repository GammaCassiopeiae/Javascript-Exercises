importNode – Deep vs Shallow
Deep import (true) copies the node and all its children. Shallow import (false) copies only the node itself.

span.textContent = "child";
div.appendChild(span);

// Deep: copies div AND span
const deep = document.importNode(div, true);

// Shallow: copies div only (no span)
const shallow = document.importNode(div, false);

const obj = { a: 1 };
Object.freeze(obj);
Object.isFrozen(obj); // true

isFrozen() – Deep Freeze
isFrozen only checks shallow freeze. Nested objects can still change.
const obj = { nested: { x: 1 } };
Object.freeze(obj);
obj.nested.x = 99; // still works!
