Balanced Binary Tree

Check if a binary tree is height-balanced

Difficulty Easy
Time O(n)
Space O(n)
Pattern DFS

A binary tree is height-balanced if the heights of the two subtrees of every node differ by at most 1.

Compute the height of each subtree bottom-up and abort with -1 when a node is unbalanced.

JAVASCRIPT SOLUTION
function isBalanced(root) {
    function height(node) {
        if (node === null) {
            return 0;
        }

        const leftHeight = height(node.left);
        if (leftHeight === -1) {
            return -1;
        }

        const rightHeight = height(node.right);
        if (rightHeight === -1) {
            return -1;
        }

        if (Math.abs(leftHeight - rightHeight) > 1) {
            return -1;
        }

        return Math.max(leftHeight, rightHeight) + 1;
    }

    return height(root) !== -1;
}

// Example
//     3          → balanced
//    / \
//   9  20
//      / \
//     15  7

//     1          → NOT balanced
//    / \
//   2   2
//  /
// 3

> isBalanced(root([3,9,20,null,null,15,7])) → true

> isBalanced(root([1,2,2,3,null,null,null])) → false
