Best Time to Buy and Sell Stock

Find the maximum profit from one transaction

Difficulty Easy
Time O(n)
Space O(1)
Pattern Sliding Window

Given an array prices where prices[i] is the price on day i, return the maximum profit from buying on one day and selling on a later day.

Track the minimum price seen so far and compute profit at each step.

JAVASCRIPT SOLUTION
function maxProfit(prices) {
    let minPrice = Infinity;
    let maxProfit = 0;

    for (const price of prices) {
        if (price < minPrice) {
            minPrice = price;
        } else if (price - minPrice > maxProfit) {
            maxProfit = price - minPrice;
        }
    }

    return maxProfit;
}

// Example
const prices = [7, 1, 5, 3, 6, 4];
console.log(maxProfit(prices)); // 5

> maxProfit([7,1,5,3,6,4]) → 5 (buy at 1, sell at 6)
