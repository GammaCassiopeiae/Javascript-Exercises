Bogo Sort

Shuffle until it's sorted — by luck

Category Sorting
Time O(n!) worst
Space O(1)
Pattern Randomization

Sort an array by shuffling it randomly until, by pure chance, it comes out sorted. Also known as "stupid sort".

Purely pedagogical — expected complexity of n! shuffle attempts. Never use in production.

JAVASCRIPT SOLUTION
function isSorted(arr) {
    for (let i = 1; i < arr.length; i++) {
        if (arr[i - 1] > arr[i]) {
            return false;
        }
    }
    return true;
}

function shuffle(arr) {
    for (let i = arr.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [arr[i], arr[j]] = [arr[j], arr[i]];
    }
    return arr;
}

function bogoSort(arr) {
    const a = [...arr];
    while (!isSorted(a)) {
        shuffle(a);
    }
    return a;
}

// Example (may take a while for n > 8!)
console.log(bogoSort([3, 1, 2]));
// → [1, 2, 3]  ... eventually

> bogoSort([3,1,2]) → [1,2,3] (expected, given enough shuffles)
