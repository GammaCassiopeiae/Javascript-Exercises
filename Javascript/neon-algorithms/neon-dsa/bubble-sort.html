Bubble Sort

Repeatedly swap adjacent out-of-order pairs

Category Sorting
Time O(n²)
Space O(1)
Pattern Adjacent Swaps

Sort an array in place by repeatedly passing through it, swapping adjacent elements that are out of order until no swaps occur.

A flag stops early when the array is already sorted; each pass bubbles the largest remaining value to the end.

JAVASCRIPT SOLUTION
function bubbleSort(arr) {
    const a = [...arr];
    const n = a.length;

    for (let i = 0; i < n - 1; i++) {
        let swapped = false;

        for (let j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                [a[j], a[j + 1]] = [a[j + 1], a[j]];
                swapped = true;
            }
        }

        if (!swapped) break;  // already sorted
    }

    return a;
}

// Example
console.log(bubbleSort([5, 2, 9, 1, 5, 6]));
// → [1, 2, 5, 5, 6, 9]

> bubbleSort([5,2,9,1,5,6]) → [1,2,5,5,6,9]
