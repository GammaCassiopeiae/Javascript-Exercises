Bucket Sort

Distribute items into buckets, sort, concatenate

Category Sorting
Time O(n + k) best
Space O(n)
Pattern Distribution Sort

Sort evenly distributed data by scattering elements into ordered buckets, sorting each bucket (here with insertion sort), then concatenating buckets in order.

Places values in a known range; the example below maps 0–1 floats to n buckets.

JAVASCRIPT SOLUTION
function insertionSort(arr) {
    for (let i = 1; i < arr.length; i++) {
        const key = arr[i];
        let j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
    return arr;
}

// For floating point values in [0, 1)
function bucketSort(arr, bucketCount = arr.length) {
    const buckets = Array.from({ length: bucketCount }, () => []);

    for (const value of arr) {
        const index = Math.floor(value * bucketCount);
        buckets[index].push(value);
    }

    const result = [];
    for (const bucket of buckets) {
        result.push(...insertionSort(bucket));
    }

    return result;
}

// Example
console.log(bucketSort([0.42, 0.32, 0.33, 0.52, 0.37, 0.47]));
// → [0.32, 0.33, 0.37, 0.42, 0.47, 0.52]
