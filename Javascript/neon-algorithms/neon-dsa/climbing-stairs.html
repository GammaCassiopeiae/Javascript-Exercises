Climbing Stairs

Count ways to reach the top climbing one or two steps

Difficulty Easy
Time O(n)
Space O(1)
Pattern Dynamic Programming

Each time you can climb 1 or 2 steps. Count the distinct ways to reach the top of n stairs.

This is the Fibonacci sequence: ways(n) = ways(n-1) + ways(n-2). Use iteration to keep space constant.

JAVASCRIPT SOLUTION
function climbStairs(n) {
    if (n <= 2) {
        return n;
    }

    let prev = 1;  // ways for n = 1
    let curr = 2;  // ways for n = 2

    for (let i = 3; i <= n; i++) {
        const next = prev + curr;
        prev = curr;
        curr = next;
    }

    return curr;
}

// Example
console.log(climbStairs(2)); // 2
console.log(climbStairs(3)); // 3
console.log(climbStairs(4)); // 5

> climbStairs(2) → 2 (1+1, 2)

> climbStairs(3) → 3 (1+1+1, 1+2, 2+1)

> climbStairs(4) → 5
