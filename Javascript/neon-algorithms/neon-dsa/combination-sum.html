Combination Sum

Unique combos of candidates summing to a target

Difficulty Medium
Time O(2^n)
Space O(target)
Pattern Backtracking

Given distinct candidates and a target, return all unique combinations where candidates sum to the target. The same candidate may be reused unlimited times.

Backtrack — choose a candidate, recurse, then undo — and let the start index keep combinations from repeating.

JAVASCRIPT SOLUTION
function combinationSum(candidates, target) {
    const result = [];

    function backtrack(start, path, remaining) {
        if (remaining === 0) {
            result.push([...path]);
            return;
        }
        if (remaining < 0) {
            return;
        }

        for (let i = start; i < candidates.length; i++) {
            path.push(candidates[i]);
            backtrack(i, path, remaining - candidates[i]); // reuse allowed
            path.pop();
        }
    }

    backtrack(0, [], target);
    return result;
}

// Example
console.log(combinationSum([2, 3, 6, 7], 7));
// → [[2, 2, 3], [7]]

> combinationSum([2,3,6,7], 7) → [[2,2,3],[7]]
