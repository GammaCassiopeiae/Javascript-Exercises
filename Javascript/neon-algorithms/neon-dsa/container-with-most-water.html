Container With Most Water

Max area between two vertical lines

Difficulty Medium
Time O(n)
Space O(1)
Pattern Two Pointers

Given an array of heights, choose two lines that together with the x-axis form a container holding the most water: area = width × min(left, right).

Start pointers at both ends and always move the shorter side inward — the width shrinks, so only a taller barrier can improve the area.

JAVASCRIPT SOLUTION
function maxArea(heights) {
    let left = 0;
    let right = heights.length - 1;
    let maxWater = 0;

    while (left < right) {
        const width = right - left;
        const area = width * Math.min(heights[left], heights[right]);
        maxWater = Math.max(maxWater, area);

        // Move the shorter line inward
        if (heights[left] < heights[right]) {
            left++;
        } else {
            right--;
        }
    }

    return maxWater;
}

// Example
console.log(maxArea([1, 8, 6, 2, 5, 4, 8, 3, 7])); // 49

> maxArea([1,8,6,2,5,4,8,3,7]) → 49
