Contains Duplicate

Check if any value appears at least twice

Difficulty Easy
Time O(n)
Space O(n)
Pattern Hash Set

Given an integer array nums, return true if any value appears at least twice, otherwise false.

Insert every element into a set; the first repeat reveals a duplicate in linear time.

JAVASCRIPT SOLUTION
function containsDuplicate(nums) {
    const seen = new Set();

    for (const num of nums) {
        if (seen.has(num)) {
            return true;
        }
        seen.add(num);
    }

    return false;
}

// Example
console.log(containsDuplicate([1, 2, 3, 1]));  // true
console.log(containsDuplicate([1, 2, 3, 4]));  // false

> containsDuplicate([1,2,3,1]) → true

> containsDuplicate([1,2,3,4]) → false
