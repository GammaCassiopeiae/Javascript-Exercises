Counting Bits

Number of 1 bits for every integer 0…n

Difficulty Easy
Time O(n)
Space O(1)
Pattern Dynamic Programming · Bit

Return an array where ans[i] is the number of 1 bits in the binary representation of i, for every 0 ≤ i ≤ n.

ans[i] = ans[i >> 1] + (i & 1) — drop the least significant bit and reuse the earlier count.

JAVASCRIPT SOLUTION
function countBits(n) {
    const ans = new Array(n + 1).fill(0);

    for (let i = 1; i <= n; i++) {
        ans[i] = ans[i >> 1] + (i & 1);
    }

    return ans;
}

// Example
console.log(countBits(2)); // [0, 1, 1]
console.log(countBits(5)); // [0, 1, 1, 2, 1, 2]

// 0→0, 1→1, 2→10(1), 3→11(2),
// 4→100(1), 5→101(2)
