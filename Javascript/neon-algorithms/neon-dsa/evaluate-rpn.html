Evaluate Reverse Polish Notation

Evaluate tokens in postfix order

Difficulty Medium
Time O(n)
Space O(n)
Pattern Stack

Given an array of tokens representing an arithmetic expression in Reverse Polish Notation, evaluate it and return the integer result.

Push operands onto a stack; pop two values when an operator appears, apply it, and push the result back.

JAVASCRIPT SOLUTION
function evalRPN(tokens) {
    const stack = [];

    for (const token of tokens) {
        if (!['+', '-', '*', '/'].includes(token)) {
            stack.push(Number(token));
        } else {
            const b = stack.pop();
            const a = stack.pop();

            if (token === '+') stack.push(a + b);
            if (token === '-') stack.push(a - b);
            if (token === '*') stack.push(a * b);
            if (token === '/') {
                stack.push(Math.trunc(a / b));
            }
        }
    }

    return stack.pop();
}

// Example
const tokens = ["2", "1", "+", "3", "*"];
console.log(evalRPN(tokens)); // 9  ( (2 + 1) * 3 )

const tokens2 = ["10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"];
console.log(evalRPN(tokens2)); // 22
