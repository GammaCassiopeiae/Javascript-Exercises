Find Median from Data Stream

Median as numbers arrive incrementally

Difficulty Hard
Add Time O(log n)
Median Time O(1)
Pattern Two Heaps

Design a class with addNum(num) and findMedian(). The median changes as numbers stream in.

Keep a max-heap for the lower half and a min-heap for the upper half, balancing sizes; the median is a heap peek (or their average).

JAVASCRIPT SOLUTION
// Simple binary-search insertion (array-backed demo).
// A production version uses max/min heaps for O(log n).
class MedianFinder {
    constructor() {
        this.nums = [];
    }

    addNum(num) {
        // binary search insertion point (sorted array)
        let left = 0;
        let right = this.nums.length;
        while (left < right) {
            const mid = Math.floor((left + right) / 2);
            if (this.nums[mid] < num) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        this.nums.splice(left, 0, num);
    }

    findMedian() {
        const n = this.nums.length;
        const mid = Math.floor(n / 2);

        if (n % 2 === 1) {
            return this.nums[mid];
        }
        return (this.nums[mid - 1] + this.nums[mid]) / 2;
    }
}

// Example
const mf = new MedianFinder();
mf.addNum(1);
mf.addNum(2);
mf.findMedian(); // 1.5
mf.addNum(3);
mf.findMedian(); // 2

> add 1, add 2 → findMedian() = 1.5

> add 3 → findMedian() = 2
