First Bad Version

Find the first bad version using a given API

Difficulty Easy
Time O(log n)
Space O(1)
Pattern Binary Search

Versions 1 through n; isBadVersion(version) tells if a version is bad. Once a version is bad, all later ones are bad.

Binary search for the boundary where "good" becomes "bad" — the first true.

JAVASCRIPT SOLUTION
// isBadVersion is provided by the API
// function isBadVersion(version) { ... }

function firstBadVersion(n) {
    let left = 1;
    let right = n;

    while (left < right) {
        const mid = Math.floor(left + (right - left) / 2);

        if (isBadVersion(mid)) {
            right = mid;    // still may be earlier bad versions
        } else {
            left = mid + 1; // check the right half
        }
    }

    return left;
}

// Example: n = 5, first bad = 4
// versions: 1 = good, 2 = good, 3 = good,
//           4 = BAD,   5 = BAD
console.log(firstBadVersion(5)); // 4
