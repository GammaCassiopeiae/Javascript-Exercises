Gas Station

Find the start station for a full circuit

Difficulty Medium
Time O(n)
Space O(1)
Pattern Greedy

There are gas stations around a circular route with gas[i] available and cost[i] to reach the next station. Return the starting index that completes a full loop, or -1.

If the total gas is less than the total cost it's impossible. A single pass restarts the candidate whenever the tank drops negative.

JAVASCRIPT SOLUTION
function canCompleteCircuit(gas, cost) {
    let total = 0;
    let current = 0;
    let start = 0;

    for (let i = 0; i < gas.length; i++) {
        total += gas[i] - cost[i];
        current += gas[i] - cost[i];

        // can't reach i+1 from start — restart after i
        if (current < 0) {
            start = i + 1;
            current = 0;
        }
    }

    return total < 0 ? -1 : start;
}

// Example
console.log(canCompleteCircuit([1, 2, 3, 4, 5], [3, 4, 5, 1, 2])); // 3
console.log(canCompleteCircuit([2, 3, 4], [3, 4, 3]));             // -1

> canCompleteCircuit([1,2,3,4,5], [3,4,5,1,2]) → 3

> canCompleteCircuit([2,3,4], [3,4,3]) → -1
