House Robber II

Rob a circular arrangement of houses

Difficulty Medium
Time O(n)
Space O(1)
Pattern Dynamic Programming

Houses form a circle (first and last are adjacent). Max loot without robbing adjacent houses.

The first and last houses can't both be robbed — solve the line twice: once excluding house 0, once excluding house n−1, and take the better result.

JAVASCRIPT SOLUTION
function robber(nums) {  // line robber (from House Robber)
    let prev = 0;
    let curr = 0;

    for (const num of nums) {
        const next = Math.max(curr, prev + num);
        prev = curr;
        curr = next;
    }

    return curr;
}

function rob(nums) {
    if (nums.length === 1) {
        return nums[0];
    }

    const skipFirst = robber(nums.slice(1));        // exclude house 0
    const skipLast = robber(nums.slice(0, -1));     // exclude last house

    return Math.max(skipFirst, skipLast);
}

// Example
console.log(rob([2, 3, 2]));    // 3 (can't take both 2s)
console.log(rob([1, 2, 3, 1])); // 4 (1 + 3)

> rob([2,3,2]) → 3

> rob([1,2,3,1]) → 4
