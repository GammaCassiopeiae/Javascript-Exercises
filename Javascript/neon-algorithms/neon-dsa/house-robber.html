House Robber

Max loot without robbing adjacent houses

Difficulty Medium
Time O(n)
Space O(1)
Pattern Dynamic Programming

Houses in a line each hold nums[i]. Rob the maximum total without robbing two adjacent houses.

At each house, choose between skipping it (previous total) or robbing it (two houses back + this amount).

JAVASCRIPT SOLUTION
function rob(nums) {
    let prev = 0;  // dp[i-2]
    let curr = 0;  // dp[i-1]

    for (const num of nums) {
        const next = Math.max(curr, prev + num);
        prev = curr;
        curr = next;
    }

    return curr;
}

// Example
console.log(rob([1, 2, 3, 1])); // 4 (house 1 + house 3)
console.log(rob([2, 7, 9, 3, 1])); // 12 (2 + 9 + 1)

> rob([1,2,3,1]) → 4

> rob([2,7,9,3,1]) → 12
