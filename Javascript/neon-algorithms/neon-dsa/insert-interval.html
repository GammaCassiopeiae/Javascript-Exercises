Insert Interval

Insert a new interval into a sorted non-overlapping list

Difficulty Medium
Time O(n)
Space O(n)
Pattern Intervals

Given a sorted array of non-overlapping intervals and a newInterval, insert it (merging overlaps) while keeping the list sorted and non-overlapping.

Add intervals ending before the new one, merge any that overlap, then append the rest — rebase the merged window on each collapse.

JAVASCRIPT SOLUTION
function insert(intervals, newInterval) {
    const result = [];
    let [start, end] = newInterval;
    let i = 0;

    // Intervals entirely before the new one
    while (i < intervals.length && intervals[i][1] < start) {
        result.push(intervals[i]);
        i++;
    }

    // Merge all overlapping intervals
    while (i < intervals.length && intervals[i][0] <= end) {
        start = Math.min(start, intervals[i][0]);
        end = Math.max(end, intervals[i][1]);
        i++;
    }
    result.push([start, end]);

    // Remaining intervals after the merged block
    while (i < intervals.length) {
        result.push(intervals[i]);
        i++;
    }

    return result;
}

// Example
const intervals = [[1, 3], [6, 9]];
console.log(insert(intervals, [2, 5]));
// → [[1, 5], [6, 9]]

> insert([[1,3],[6,9]], [2,5]) → [[1,5],[6,9]]

> insert([[1,2],[3,5],[6,7]], [4,8]) → [[1,2],[3,8]]
