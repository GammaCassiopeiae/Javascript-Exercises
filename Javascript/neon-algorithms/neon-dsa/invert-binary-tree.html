Invert Binary Tree

Mirror a binary tree left to right

Difficulty Easy
Time O(n)
Space O(n)
Pattern DFS

Given the root of a binary tree, invert the tree by swapping the left and right child of every node.

Recursively swap children with a depth-first traversal. The return value is the new root.

JAVASCRIPT SOLUTION
function invertTree(root) {
    if (root === null) {
        return null;
    }

    // Swap the children
    const temp = root.left;
    root.left = invertTree(root.right);
    root.right = invertTree(temp);

    return root;
}

// Example
//      4           4
//    /   \       /   \
//   2     7  →  7     2
//  / \   / \   / \   / \
// 1   3 6   9 9   6 3   1

> invertTree(root) → mirrored tree with left/right swapped at every level
