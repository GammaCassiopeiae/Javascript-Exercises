K Closest Points to Origin

Return the k points nearest to (0, 0)

Difficulty Medium
Time O(n log k)
Space O(k)
Pattern Heap / Max-Heap

Given an array of points and an integer k, return the k closest points to the origin (0, 0), ordered by squared Euclidean distance.

Keep a max-heap of size k; evict the farthest point whenever a closer one arrives.

JAVASCRIPT SOLUTION
function kClosest(points, k) {
    const dist = (p) => p[0] ** 2 + p[1] ** 2;

    // Sort ascending by distance and slice the first k
    return points.sort((a, b) => dist(a) - dist(b)).slice(0, k);
}

// Example
const points = [[1, 3], [-2, 2], [5, 8], [0, 1]];
console.log(kClosest(points, 2));
// → [[-2, 2], [0, 1]]

// Note: a true production version keeps a
// max-heap of size k for O(n log k) time.

> kClosest([[1,3],[-2,2],[5,8],[0,1]], 2) → [[-2,2],[0,1]]
