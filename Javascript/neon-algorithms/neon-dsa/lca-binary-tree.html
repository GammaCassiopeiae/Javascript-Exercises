Lowest Common Ancestor of a Binary Tree

Find the LCA in a general binary tree

Difficulty Medium
Time O(n)
Space O(n)
Pattern DFS · Postorder

Given any binary tree and two distinct nodes p and q, return their lowest common ancestor — the deepest node that is an ancestor of both.

Postorder search returns the node itself when found, bubbles BOTH matches up, and the first node whose subtrees each contain one match is the LCA.

JAVASCRIPT SOLUTION
function lowestCommonAncestor(root, p, q) {
    if (root === null || root === p || root === q) {
        return root;
    }

    const left = lowestCommonAncestor(root.left, p, q);
    const right = lowestCommonAncestor(root.right, p, q);

    // One match found in each subtree → root is the LCA
    if (left !== null && right !== null) {
        return root;
    }

    return left !== null ? left : right;
}

// Example
//       3
//      / \
//     5   1
//    / \   \
//   6   2   0
//      / \
//     7   4
// LCA of 5 and 1 → 3
// LCA of 5 and 4 → 5

> LCA(root, node(5), node(1)) → node(3)

> LCA(root, node(5), node(4)) → node(5)
