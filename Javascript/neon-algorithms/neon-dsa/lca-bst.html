Lowest Common Ancestor of BST

Find the lowest common ancestor in a binary search tree

Difficulty Easy
Time O(log n)
Space O(1)
Pattern BST Property

Given a BST and two node values p and q, return the lowest node that is an ancestor of both.

Walk down the tree: if both values are smaller, go left; if both are larger, go right; otherwise the current node is the LCA.

JAVASCRIPT SOLUTION
function lowestCommonAncestor(root, p, q) {
    let current = root;

    while (current !== null) {
        // Both on the left side
        if (p.val < current.val && q.val < current.val) {
            current = current.left;
        }
        // Both on the right side
        else if (p.val > current.val && q.val > current.val) {
            current = current.right;
        }
        // Split point — current is the LCA
        else {
            return current;
        }
    }

    return null;
}

// Example BST with values 6, 2, 8, 0, 4, 7, 9
// LCA of 2 and 8 → 6
// LCA of 2 and 4 → 2

> LCA(root, node(2), node(8)) → node(6)
