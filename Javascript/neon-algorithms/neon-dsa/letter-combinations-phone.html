Letter Combinations of a Phone Number

All letter strings a digit string can make

Difficulty Medium
Time O(4ⁿ)
Space O(n)
Pattern Backtracking

Given a string of digits 2–9, return every possible letter combination the digits could map to (phone keypad, each digit 3 or 4 letters).

Backtrack, adding one letter per digit position until the path length equals the input length.

JAVASCRIPT SOLUTION
const KEYPAD = {
    '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
    '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
};

function letterCombinations(digits) {
    if (digits.length === 0) {
        return [];
    }

    const result = [];

    function backtrack(index, path) {
        if (path.length === digits.length) {
            result.push(path);
            return;
        }

        for (const letter of KEYPAD[digits[index]]) {
            backtrack(index + 1, path + letter);
        }
    }

    backtrack(0, "");
    return result;
}

// Example
console.log(letterCombinations("23"));
// → ["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]

> letterCombinations("23") → 9 combinations
