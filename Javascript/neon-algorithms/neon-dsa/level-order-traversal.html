Binary Tree Level Order Traversal

Return node values level by level

Difficulty Medium
Time O(n)
Space O(n)
Pattern BFS

Given the root of a binary tree, return the level order traversal — node values grouped by depth from top to bottom.

Breadth-first search processes the queue one whole level at a time, collecting each row into its own array.

JAVASCRIPT SOLUTION
function levelOrder(root) {
    if (root === null) {
        return [];
    }

    const result = [];
    const queue = [root];

    while (queue.length) {
        const levelSize = queue.length;
        const level = [];

        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift();
            level.push(node.val);

            if (node.left !== null) queue.push(node.left);
            if (node.right !== null) queue.push(node.right);
        }

        result.push(level);
    }

    return result;
}

// Example
//       3
//      / \
//     9  20
//       /  \
//      15   7
// → [[3], [9, 20], [15, 7]]

> levelOrder(root([3,9,20,null,null,15,7])) → [[3],[9,20],[15,7]]
