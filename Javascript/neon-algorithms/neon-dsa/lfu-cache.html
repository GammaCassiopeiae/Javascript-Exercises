LFU Cache

Least frequently used cache eviction

Difficulty Hard
Get O(1)
Put O(1)
Pattern Freq Map + Doubly Linked Lists

Design an LFU cache: evict the least frequently used key when at capacity, breaking ties with least recently used. Both operations in O(1).

Keep frequency-count maps and a "freq → list" structure; promote a key's list on every access and evict from the lowest non-empty frequency.

JAVASCRIPT SOLUTION
// O(1) LFU using Maps keyed by frequency.
// Each freq bucket is itself an insertion-ordered Map (LRU within freq).
class LFUCache {
    constructor(capacity) {
        this.capacity = capacity;
        this.values = new Map();      // key → value
        this.freq = new Map();        // key → frequency
        this.buckets = new Map();     // freq → Map(key → true)
        this.minFreq = 0;
    }

    get(key) {
        if (!this.values.has(key)) return -1;

        const f = this.freq.get(key);
        this.buckets.get(f).delete(key);
        this.freq.set(key, f + 1);
        if (!this.buckets.has(f + 1)) this.buckets.set(f + 1, new Map());
        this.buckets.get(f + 1).set(key, true);

        if (f === this.minFreq && this.buckets.get(f).size === 0) {
            this.minFreq++;
        }

        return this.values.get(key);
    }

    put(key, value) {
        if (this.capacity === 0) return;

        if (this.values.has(key)) {
            this.values.set(key, value);
            this.get(key);  // bump frequency
            return;
        }

        if (this.values.size >= this.capacity) {
            // evict least frequent, then least recently used
            const lfuKeys = this.buckets.get(this.minFreq);
            const evict = lfuKeys.keys().next().value;
            lfuKeys.delete(evict);
            this.values.delete(evict);
            this.freq.delete(evict);
        }

        this.values.set(key, value);
        this.freq.set(key, 1);
        if (!this.buckets.has(1)) this.buckets.set(1, new Map());
        this.buckets.get(1).set(key, true);
        this.minFreq = 1;
    }
}

// Example
const cache = new LFUCache(2);
cache.put(1, 1);
cache.put(2, 2);
cache.get(1);       // 1  (freq of 1 → 2)
cache.put(3, 3);    // evicts key 2 (lowest freq)
cache.get(2);       // -1

> LFU(2): put(1,1), put(2,2) → get(1) = 1

> put(3,3) evicts 2 (freq 1) → get(2) = -1
