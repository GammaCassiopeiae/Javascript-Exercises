Linear Search

Scan for the target in any array

Category Search
Time O(n)
Space O(1)
Pattern Brute Force Scan

Find the index of a target value in an array, or -1. Works on unsorted data, unlike binary search.

Check each element in order and return the first match. This is the baseline every faster search improves on.

JAVASCRIPT SOLUTION
function linearSearch(arr, target) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] === target) {
            return i;
        }
    }
    return -1;
}

// Example
console.log(linearSearch([5, 3, 8, 1, 9, 2], 8)); // 2
console.log(linearSearch([5, 3, 8, 1, 9, 2], 4)); // -1

> linearSearch([5,3,8,1,9,2], 8) → 2

> linearSearch([5,3,8,1,9,2], 4) → -1
