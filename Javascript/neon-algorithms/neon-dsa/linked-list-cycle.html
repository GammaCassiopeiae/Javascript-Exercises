Linked List Cycle

Detect a cycle in a linked list

Difficulty Easy
Time O(n)
Space O(1)
Pattern Fast & Slow Pointers

Given the head of a linked list, determine if it contains a cycle. A cycle occurs when some node's next points back to an earlier node.

Move a slow pointer one step and a fast pointer two steps. If they meet, a cycle exists.

JAVASCRIPT SOLUTION
function hasCycle(head) {
    let slow = head;
    let fast = head;

    while (fast !== null && fast.next !== null) {
        slow = slow.next;
        fast = fast.next.next;

        if (slow === fast) {
            return true;
        }
    }

    return false;
}

// Example
// 3 → 2 → 0 → -4 (tail points back to node 2)
// hasCycle(head) → true

// 1 → 2 → null
// hasCycle(head) → false

> hasCycle(cycleHead) → true

> hasCycle(linearHead) → false
