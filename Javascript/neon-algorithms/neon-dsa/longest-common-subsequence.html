Longest Common Subsequence

Longest subsequence shared by two strings

Difficulty Medium
Time O(m · n)
Space O(m · n)
Pattern Dynamic Programming

Given two strings text1 and text2, return the length of their longest common subsequence, or 0.

When characters match, add 1 to the diagonal; otherwise take the max of dropping one character from either string.

JAVASCRIPT SOLUTION
function longestCommonSubsequence(text1, text2) {
    const m = text1.length;
    const n = text2.length;
    const dp = Array.from({ length: m + 1 },
                          () => new Array(n + 1).fill(0));

    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (text1[i - 1] === text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[m][n];
}

// Example
console.log(longestCommonSubsequence("abcde", "ace")); // 3 ("ace")
console.log(longestCommonSubsequence("abc", "abc"));   // 3
console.log(longestCommonSubsequence("abc", "def"));   // 0
