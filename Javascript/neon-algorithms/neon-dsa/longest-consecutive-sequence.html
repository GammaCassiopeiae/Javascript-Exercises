Longest Consecutive Sequence

Longest run of consecutive numbers

Difficulty Medium
Time O(n)
Space O(n)
Pattern Hash Set

Given an unsorted integer array, return the length of the longest consecutive elements sequence (order-independent, O(n)).

Insert everything in a set; only start counting from a number whose predecessor is absent, then walk upward.

JAVASCRIPT SOLUTION
function longestConsecutive(nums) {
    const set = new Set(nums);
    let best = 0;

    for (const num of nums) {
        // only start from the beginning of a run
        if (set.has(num - 1)) continue;

        let length = 1;
        let next = num + 1;

        while (set.has(next)) {
            length++;
            next++;
        }

        best = Math.max(best, length);
    }

    return best;
}

// Example
console.log(longestConsecutive([100, 4, 200, 1, 3, 2])); // 4 (1, 2, 3, 4)
console.log(longestConsecutive([0, 3, 7, 2, 5, 8, 4, 6, 0, 1])); // 9
