Longest Increasing Subsequence

Longest strictly increasing subsequence length

Difficulty Medium
Time O(n²)
Space O(n)
Pattern Dynamic Programming

Given an integer array nums, return the length of the longest strictly increasing subsequence (elements stay in order but need not be contiguous).

dp[i] = 1 + best dp[j] among elements before i that are smaller than nums[i]. O(n log n) is possible with binary search + patience sorting.

JAVASCRIPT SOLUTION
function lengthOfLIS(nums) {
    const dp = new Array(nums.length).fill(1);
    let maxLen = 1;

    for (let i = 1; i < nums.length; i++) {
        for (let j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }

    return maxLen;
}

// Example
console.log(lengthOfLIS([10, 9, 2, 5, 3, 7, 101, 18]));
// → 4  ([2, 3, 7, 101])

console.log(lengthOfLIS([0, 1, 0, 3, 2, 3])); // 4
console.log(lengthOfLIS([7, 7, 7, 7]));       // 1 (strict)
