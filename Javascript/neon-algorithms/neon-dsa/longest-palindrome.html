Longest Palindrome

Longest palindrome length that can be built from a string

Difficulty Easy
Time O(n)
Space O(1)
Pattern Hash Map

Given a string s, return the length of the longest palindrome that can be built from its letters. Letters can be rearranged.

Every even-frequency letter can be used in full; odd frequencies contribute count - 1, and at most one odd letter can sit in the center.

JAVASCRIPT SOLUTION
function longestPalindrome(s) {
    const count = {};
    let length = 0;
    let hasOdd = false;

    for (const char of s) {
        count[char] = (count[char] || 0) + 1;
    }

    for (const char in count) {
        if (count[char] % 2 === 0) {
            length += count[char];
        } else {
            length += count[char] - 1;
            hasOdd = true;
        }
    }

    return hasOdd ? length + 1 : length;
}

// Example
console.log(longestPalindrome("abccccdd")); // 7 ("dccaccd")
console.log(longestPalindrome("a"));        // 1
console.log(longestPalindrome("bb"));       // 2

> longestPalindrome("abccccdd") → 7

> longestPalindrome("a") → 1
