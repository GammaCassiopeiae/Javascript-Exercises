Longest Substring Without Repeating Characters

Find the longest substring with all unique characters

Difficulty Medium
Time O(n)
Space O(min(n, m))
Pattern Sliding Window

Given a string s, return the length of the longest substring that contains no repeating characters.

Slide a window with two pointers, tracking the last seen index of each character to jump the left pointer past duplicates.

JAVASCRIPT SOLUTION
function lengthOfLongestSubstring(s) {
    const lastIndex = {};
    let left = 0;
    let maxLen = 0;

    for (let right = 0; right < s.length; right++) {
        const char = s[right];

        if (char in lastIndex && lastIndex[char] >= left) {
            left = lastIndex[char] + 1;
        }

        lastIndex[char] = right;
        maxLen = Math.max(maxLen, right - left + 1);
    }

    return maxLen;
}

// Example
console.log(lengthOfLongestSubstring("abcabcbb")); // 3 ("abc")
console.log(lengthOfLongestSubstring("bbbbb"));    // 1 ("b")
console.log(lengthOfLongestSubstring("pwwkew"));   // 3 ("wke")
