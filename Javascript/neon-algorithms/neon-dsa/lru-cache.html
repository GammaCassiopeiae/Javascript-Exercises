LRU Cache

Least recently used cache in O(1)

Difficulty Medium
Get O(1)
Put O(1)
Pattern Map + Doubly Linked List

Design an LRU cache with get(key) and put(key, value), both O(1), evicting the least recently used key when capacity is exceeded.

A hash map of nodes plus a doubly linked list keeps recency order; every access moves the node to the tail (most recent).

JAVASCRIPT SOLUTION
class LRUCache {
    constructor(capacity) {
        this.capacity = capacity;
        this.map = new Map();
    }

    get(key) {
        if (!this.map.has(key)) {
            return -1;
        }
        // refresh recency by re-inserting
        const value = this.map.get(key);
        this.map.delete(key);
        this.map.set(key, value);
        return value;
    }

    put(key, value) {
        if (this.map.has(key)) {
            this.map.delete(key);
        }
        this.map.set(key, value);

        if (this.map.size > this.capacity) {
            // evict the least recently used (first inserted)
            const oldest = this.map.keys().next().value;
            this.map.delete(oldest);
        }
    }
}

// Map preserves insertion order, so a Map is a
// clean O(1) implementation for JS.
// Example
const cache = new LRUCache(2);
cache.put(1, 1);
cache.put(2, 2);
cache.get(1);       // 1 (key 1 becomes most recent)
cache.put(3, 3);    // evicts key 2
cache.get(2);       // -1

> LRU(2): put(1,1), put(2,2) → get(1) = 1

> put(3,3) evicts 2 → get(2) = -1
