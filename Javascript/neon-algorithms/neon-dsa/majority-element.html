Majority Element

Find the element appearing more than n/2 times

Difficulty Easy
Time O(n)
Space O(1)
Pattern Boyer-Moore Vote

Given an array nums of size n, return the majority element that appears more than n / 2 times.

Boyer-Moore voting tracks a candidate and a counter: matching votes increment, non-matching decrement; when the counter hits zero, pick a new candidate.

JAVASCRIPT SOLUTION
function majorityElement(nums) {
    let candidate = null;
    let count = 0;

    for (const num of nums) {
        if (count === 0) {
            candidate = num;
        }
        count += (num === candidate) ? 1 : -1;
    }

    return candidate;
}

// Example
const nums = [2, 2, 1, 1, 1, 2, 2];
console.log(majorityElement(nums)); // 2
