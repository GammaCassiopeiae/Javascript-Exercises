Binary Tree Maximum Path Sum

Max sum along any root-to-node path

Difficulty Hard
Time O(n)
Space O(n)
Pattern DFS · Postorder

A path is any sequence of nodes where each pair has an edge; a path need not pass through the root. Return the maximum path sum (values can be negative).

Postorder: at each node, the best single branch is node.val + max(leftGain, rightGain, 0), and the best path through it is node.val + leftGain + rightGain.

JAVASCRIPT SOLUTION
function maxPathSum(root) {
    let best = -Infinity;

    function gain(node) {
        if (node === null) {
            return 0;
        }

        // only embrace positive contributions
        const leftGain = Math.max(gain(node.left), 0);
        const rightGain = Math.max(gain(node.right), 0);

        // path that bends through this node
        const throughNode = node.val + leftGain + rightGain;
        best = Math.max(best, throughNode);

        // best single branch to offer the parent
        return node.val + Math.max(leftGain, rightGain);
    }

    gain(root);
    return best;
}

// Example
//    -10
//    /  \
//   9   20
//      /  \
//     15   7
console.log(maxPathSum(root)); // 42  (15 + 20 + 7)

> maxPathSum([-10,9,20,null,null,15,7]) → 42
