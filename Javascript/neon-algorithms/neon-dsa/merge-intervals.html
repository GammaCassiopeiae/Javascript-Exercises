Merge Intervals

Merge all overlapping intervals

Difficulty Medium
Time O(n log n)
Space O(n)
Pattern Intervals · Sort

Given an array of intervals [start, end], merge any that overlap or touch and return non-overlapping intervals covering the input.

Sort by start, then walk through: extend the current interval when the next start is smaller than the current end, otherwise close and start a new one.

JAVASCRIPT SOLUTION
function merge(intervals) {
    if (intervals.length === 0) {
        return [];
    }

    intervals.sort((a, b) => a[0] - b[0]);
    const result = [intervals[0]];

    for (let i = 1; i < intervals.length; i++) {
        const current = intervals[i];
        const last = result[result.length - 1];

        if (current[0] <= last[1]) {
            last[1] = Math.max(last[1], current[1]); // merge
        } else {
            result.push(current);
        }
    }

    return result;
}

// Example
console.log(merge([[1, 3], [2, 6], [8, 10], [15, 18]]));
// → [[1, 6], [8, 10], [15, 18]]

> merge([[1,3],[2,6],[8,10],[15,18]]) → [[1,6],[8,10],[15,18]]
