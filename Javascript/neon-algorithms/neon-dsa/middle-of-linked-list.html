Middle of the Linked List

Return the middle node of a linked list

Difficulty Easy
Time O(n)
Space O(1)
Pattern Fast & Slow Pointers

Given the head of a singly linked list, return the middle node. If two middle nodes exist, return the second one.

A slow pointer advances one node while a fast pointer advances two; when fast runs off the list, slow is at the middle.

JAVASCRIPT SOLUTION
function middleNode(head) {
    let slow = head;
    let fast = head;

    while (fast !== null && fast.next !== null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    return slow;
}

// Example
// 1 → 2 → 3 → 4 → 5
// middleNode(head) → node(3)

// 1 → 2 → 3 → 4 → 5 → 6
// middleNode(head) → node(4)   (second middle)

> middleNode(1→2→3→4→5) → node(3)

> middleNode(1→2→3→4→5→6) → node(4)
