Min Stack

A stack that returns the minimum in O(1)

Difficulty Medium
Time O(1) each
Space O(n)
Pattern Stack · Aux Stack

Design a stack supporting push, pop, top, and getMin — all in constant time.

Keep a second "min stack" that mirrors the current minimum; popping both keeps the values in sync.

JAVASCRIPT SOLUTION
class MinStack {
    constructor() {
        this.stack = [];
        this.minStack = [];
    }

    push(val) {
        this.stack.push(val);

        if (this.minStack.length === 0 ||
            val <= this.minStack[this.minStack.length - 1]) {
            this.minStack.push(val);
        }
    }

    pop() {
        const popped = this.stack.pop();
        if (popped === this.minStack[this.minStack.length - 1]) {
            this.minStack.pop();
        }
        return popped;
    }

    top() {
        return this.stack[this.stack.length - 1];
    }

    getMin() {
        return this.minStack[this.minStack.length - 1];
    }
}

// Example
const ms = new MinStack();
ms.push(-2);
ms.push(0);
ms.push(-3);
ms.getMin();   // -3
ms.pop();
ms.top();      // 0
ms.getMin();   // -2

> push(-2), push(0), push(-3) → getMin() = -3

> pop() → top() = 0 → getMin() = -2
