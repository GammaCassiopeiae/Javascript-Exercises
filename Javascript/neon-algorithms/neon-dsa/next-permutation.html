Next Permutation

Next lexicographically greater arrangement

Difficulty Medium
Time O(n)
Space O(1)
Pattern Array Manipulation

Given an array of integers, rearrange it in place into the next lexicographically greater permutation. If none exists, sort to the smallest.

Find the pivot from the right, swap it with the next larger element to its right, then reverse the suffix.

JAVASCRIPT SOLUTION
function nextPermutation(nums) {
    let pivot = -1;

    // 1. find the first descent from the right
    for (let i = nums.length - 2; i >= 0; i--) {
        if (nums[i] < nums[i + 1]) {
            pivot = i;
            break;
        }
    }

    if (pivot !== -1) {
        // 2. swap with the next larger element in the suffix
        for (let i = nums.length - 1; i > pivot; i--) {
            if (nums[i] > nums[pivot]) {
                [nums[pivot], nums[i]] = [nums[i], nums[pivot]];
                break;
            }
        }
    }

    // 3. reverse the suffix (turns it ascending)
    let left = pivot + 1;
    let right = nums.length - 1;
    while (left < right) {
        [nums[left], nums[right]] = [nums[right], nums[left]];
        left++;
        right--;
    }
}

// Example
const a = [1, 2, 3];
nextPermutation(a);
console.log(a); // [1, 3, 2]

const b = [3, 2, 1];
nextPermutation(b);
console.log(b); // [1, 2, 3] (wraps around)

> nextPermutation([1,2,3]) → [1,3,2]

> nextPermutation([3,2,1]) → [1,2,3]
