Palindromic Substrings

Count all palindromic substrings

Difficulty Medium
Time O(n²)
Space O(1)
Pattern Expand Around Center

Given a string s, return the number of palindromic substrings in it (single characters count).

Every index (and gap) is a palindrome center; expand outward and count each palindrome found.

JAVASCRIPT SOLUTION
function countSubstrings(s) {
    let count = 0;

    function expand(left, right) {
        while (left >= 0 && right < s.length &&
               s[left] === s[right]) {
            count++;   // found a palindrome
            left--;
            right++;
        }
    }

    for (let i = 0; i < s.length; i++) {
        expand(i, i);       // odd-length centers
        expand(i, i + 1);   // even-length centers
    }

    return count;
}

// Example
console.log(countSubstrings("abc"));  // 3  ("a", "b", "c")
console.log(countSubstrings("aaa"));  // 6  ("a","a","a","aa","aa","aaa")

> countSubstrings("abc") → 3

> countSubstrings("aaa") → 6
