Partition Equal Subset Sum

Split the array into two equal-sum halves

Difficulty Medium
Time O(n · target)
Space O(target)
Pattern Dynamic Programming

Given a non-empty array of positive integers, return true if it can be partitioned into two subsets with equal sum.

The total must be even; then it reduces to a subset-sum problem for total / 2.

JAVASCRIPT SOLUTION
function canPartition(nums) {
    const total = nums.reduce((a, b) => a + b, 0);
    if (total % 2 !== 0) {
        return false;
    }

    const target = total / 2;
    const dp = new Array(target + 1).fill(false);
    dp[0] = true;

    for (const num of nums) {
        for (let s = target; s >= num; s--) {
            if (dp[s - num]) {
                dp[s] = true;
            }
        }
    }

    return dp[target];
}

// Example
console.log(canPartition([1, 5, 11, 5])); // true ( [1,5,5] = 11 )
console.log(canPartition([1, 2, 3, 5]));  // false

> canPartition([1,5,11,5]) → true

> canPartition([1,2,3,5]) → false
