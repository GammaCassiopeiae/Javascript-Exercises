Product of Array Except Self

Product of all elements except the current one

Difficulty Medium
Time O(n)
Space O(1) extra
Pattern Prefix × Suffix

Return an array where each element is the product of all input elements except itself, without using division and in O(n).

Two passes — accumulate the running product from the left, then multiply by the running product from the right — into the same answer array.

JAVASCRIPT SOLUTION
function productExceptSelf(nums) {
    const n = nums.length;
    const answer = new Array(n).fill(1);

    // Left pass: product of everything to the left
    let left = 1;
    for (let i = 0; i < n; i++) {
        answer[i] = left;
        left *= nums[i];
    }

    // Right pass: multiply by product to the right
    let right = 1;
    for (let i = n - 1; i >= 0; i--) {
        answer[i] *= right;
        right *= nums[i];
    }

    return answer;
}

// Example
console.log(productExceptSelf([1, 2, 3, 4]));
// → [24, 12, 8, 6]
