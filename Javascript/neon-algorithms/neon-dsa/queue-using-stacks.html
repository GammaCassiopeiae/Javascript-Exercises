Implement Queue using Stacks

A FIFO queue built on top of two LIFO stacks

Difficulty Easy
Time Amortized O(1)
Space O(n)
Pattern Stack → Queue

Implement a first-in-first-out (FIFO) queue using only two stacks. Support push, pop, peek, and empty.

Dump the input stack into the output stack when an output is needed, reversing the order to simulate a queue.

JAVASCRIPT SOLUTION
class MyQueue {
    constructor() {
        this.input = [];
        this.output = [];
    }

    push(x) {
        this.input.push(x);
    }

    transfer() {
        if (this.output.length === 0) {
            while (this.input.length) {
                this.output.push(this.input.pop());
            }
        }
    }

    pop() {
        this.transfer();
        return this.output.pop();
    }

    peek() {
        this.transfer();
        return this.output[this.output.length - 1];
    }

    empty() {
        return this.input.length === 0 && this.output.length === 0;
    }
}

// Example
const q = new MyQueue();
q.push(1);
q.push(2);
q.peek();   // → 1  (front of the queue)
q.pop();    // → 1  (removes the front)
q.empty();  // → false

> q.peek() → 1

> q.pop() → 1

> q.empty() → false
