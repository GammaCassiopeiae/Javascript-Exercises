Ransom Note

Can the magazine letters build the ransom note?

Difficulty Easy
Time O(n+m)
Space O(1)
Pattern Hash Map

Given a ransomNote and a magazine, return true if the note can be constructed using the letters from the magazine (each letter used at most once).

Count magazine characters, then decrement as the note consumes them.

JAVASCRIPT SOLUTION
function canConstruct(ransomNote, magazine) {
    const count = {};

    for (const char of magazine) {
        count[char] = (count[char] || 0) + 1;
    }

    for (const char of ransomNote) {
        if (!count[char]) {
            return false;
        }
        count[char]--;
    }

    return true;
}

// Example
console.log(canConstruct("aa", "aab")); // true
console.log(canConstruct("aa", "ab"));  // false

> canConstruct("aa", "aab") → true

> canConstruct("aa", "ab") → false
