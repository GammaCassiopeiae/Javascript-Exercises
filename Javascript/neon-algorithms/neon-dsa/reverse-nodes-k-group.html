Reverse Nodes in k-Group

Reverse the list in chunks of size k

Difficulty Hard
Time O(n)
Space O(n/k)
Pattern Linked List · Recursion

Given the head of a linked list and an integer k, reverse the nodes in groups of k; leftover nodes at the end stay as they are.

Verify k nodes remain, reverse that section with three pointers, then recurse on the tail and reconnect.

JAVASCRIPT SOLUTION
function reverseKGroup(head, k) {
    // check we have at least k nodes
    let probe = head;
    let count = 0;
    while (probe !== null && count < k) {
        probe = probe.next;
        count++;
    }
    if (count < k) {
        return head;
    }

    // reverse the first k nodes
    let prev = null;
    let curr = head;
    for (let i = 0; i < k; i++) {
        const next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    // head is now the tail; attach the rest
    head.next = reverseKGroup(curr, k);

    return prev;  // new head of this group
}

// Example: head = 1→2→3→4→5, k = 2
// → 2 → 1 → 4 → 3 → 5

// Example: head = 1→2→3→4→5, k = 3
// → 3 → 2 → 1 → 4 → 5
