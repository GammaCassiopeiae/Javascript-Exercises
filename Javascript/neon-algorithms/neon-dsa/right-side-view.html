Binary Tree Right Side View

Values visible from the right edge

Difficulty Medium
Time O(n)
Space O(n)
Pattern BFS

Given the root of a binary tree, return the values of nodes visible when the tree is viewed from the right side, top to bottom.

Level-order traversal, keeping just the last (rightmost) node of each level.

JAVASCRIPT SOLUTION
function rightSideView(root) {
    if (root === null) {
        return [];
    }

    const result = [];
    const queue = [root];

    while (queue.length) {
        const levelSize = queue.length;
        let rightmost = null;

        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift();
            rightmost = node.val;  // last node in this level wins

            if (node.left !== null) queue.push(node.left);
            if (node.right !== null) queue.push(node.right);
        }

        result.push(rightmost);
    }

    return result;
}

// Example
//       1
//      / \
//     2   3
//      \   \
//       5   4
// → [1, 3, 4]

> rightSideView(root) → [1, 3, 4]
