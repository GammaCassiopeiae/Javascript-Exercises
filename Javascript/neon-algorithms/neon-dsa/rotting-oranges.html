Rotting Oranges

Minutes until all oranges rot

Difficulty Medium
Time O(m · n)
Space O(m · n)
Pattern Multi-Source BFS

In a grid, 0 = empty, 1 = fresh orange, 2 = rotten. Each minute, rotten oranges rot adjacent fresh ones (4 directions). Return minutes until none are fresh, or -1.

Seed all rotten oranges in the queue and count BFS "minutes" as each ring of oranges decays.

JAVASCRIPT SOLUTION
function orangesRotting(grid) {
    const rows = grid.length;
    const cols = grid[0].length;
    const queue = [];
    let fresh = 0;

    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (grid[r][c] === 2) queue.push([r, c, 0]);
            if (grid[r][c] === 1) fresh++;
        }
    }

    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    let minutes = 0;

    for (let i = 0; i < queue.length; i++) {
        const [r, c, time] = queue[i];
        minutes = Math.max(minutes, time);

        for (const [dr, dc] of dirs) {
            const nr = r + dr;
            const nc = c + dc;
            if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
            if (grid[nr][nc] !== 1) continue;

            grid[nr][nc] = 2;
            fresh--;
            queue.push([nr, nc, time + 1]);
        }
    }

    return fresh === 0 ? minutes : -1;
}

// Example
console.log(orangesRotting([[2, 1, 1], [1, 1, 0], [0, 1, 1]])); // 4
console.log(orangesRotting([[2, 1, 1], [0, 1, 1], [1, 0, 1]])); // -1

> orangesRotting([[2,1,1],[1,1,0],[0,1,1]]) → 4
