Search in Rotated Sorted Array

Find the target in a rotated sorted array

Difficulty Medium
Time O(log n)
Space O(1)
Pattern Binary Search

Given a sorted array rotated at an unknown pivot (no duplicates) and a target, return its index or -1.

At each binary-search step one half is guaranteed sorted — decide which half to descend into by comparing the target with the sorted side's bounds.

JAVASCRIPT SOLUTION
function search(nums, target) {
    let left = 0;
    let right = nums.length - 1;

    while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] === target) {
            return mid;
        }

        // Left half is sorted
        if (nums[left] <= nums[mid]) {
            if (target >= nums[left] && target < nums[mid]) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        // Right half is sorted
        else {
            if (target > nums[mid] && target <= nums[right]) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
    }

    return -1;
}

// Example (rotated at index 4)
console.log(search([4, 5, 6, 7, 0, 1, 2], 0)); // 4
console.log(search([4, 5, 6, 7, 0, 1, 2], 3)); // -1

> search([4,5,6,7,0,1,2], 0) → 4

> search([4,5,6,7,0,1,2], 3) → -1
