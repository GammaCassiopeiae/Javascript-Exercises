Sliding Window Maximum

Max of every window of size k

Difficulty Hard
Time O(n)
Space O(k)
Pattern Monotonic Deque

Given an array and window size k, return the maximum in every contiguous window.

A monotonic decreasing deque stores candidate indices; the front is the window's max, and stale indexes fall off the left.

JAVASCRIPT SOLUTION
function maxSlidingWindow(nums, k) {
    const result = [];
    const deque = [];  // indices, values decreasing

    for (let i = 0; i < nums.length; i++) {
        // evict indexes outside the window
        while (deque.length && deque[0] <= i - k) {
            deque.shift();
        }

        // keep the deque decreasing
        while (deque.length && nums[deque[deque.length - 1]] <= nums[i]) {
            deque.pop();
        }

        deque.push(i);

        // front is the max once the first window fills
        if (i >= k - 1) {
            result.push(nums[deque[0]]);
        }
    }

    return result;
}

// Example
console.log(maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3));
// → [3, 3, 5, 5, 6, 7]

> maxSlidingWindow([1,3,-1,-3,5,3,6,7], 3) → [3,3,5,5,6,7]
