Spiral Matrix

Read a matrix in clockwise spiral order

Difficulty Medium
Time O(m · n)
Space O(1)
Pattern Simulation · Boundaries

Given an m × n matrix, return all elements in clockwise spiral order (right, down, left, up) shrinking the bounds inward.

Keep four boundaries (top, right, bottom, left) and walk each edge, checking for overlap after every pass.

JAVASCRIPT SOLUTION
function spiralOrder(matrix) {
    const result = [];
    let top = 0;
    let bottom = matrix.length - 1;
    let left = 0;
    let right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        // move right
        for (let c = left; c <= right; c++) result.push(matrix[top][c]);
        top++;

        // move down
        for (let r = top; r <= bottom; r++) result.push(matrix[r][right]);
        right--;

        if (top > bottom || left > right) break;

        // move left
        for (let c = right; c >= left; c--) result.push(matrix[bottom][c]);
        bottom--;

        // move up
        for (let r = bottom; r >= top; r--) result.push(matrix[r][left]);
        left++;
    }

    return result;
}

// Example
const matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];
console.log(spiralOrder(matrix));
// → [1, 2, 3, 6, 9, 8, 7, 4, 5]

> spiralOrder([[1,2,3],[4,5,6],[7,8,9]]) → [1,2,3,6,9,8,7,4,5]
