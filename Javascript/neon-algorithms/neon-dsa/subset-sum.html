Subset Sum

Can any subset sum to the target?

Difficulty Medium
Time O(n · sum)
Space O(sum)
Pattern Dynamic Programming

Given a set of non-negative integers, determine whether a subset adds up to exactly a given target.

dp[s] tracks which sums are reachable; build the reachable set by adding each number to every existing reachable sum.

JAVASCRIPT SOLUTION
function subsetSum(nums, target) {
    const dp = new Array(target + 1).fill(false);
    dp[0] = true;

    for (const num of nums) {
        for (let s = target; s >= num; s--) {
            if (dp[s - num]) {
                dp[s] = true;
            }
        }
    }

    return dp[target];
}

// Example
console.log(subsetSum([3, 34, 4, 12, 5, 2], 9));  // true (4 + 5)
console.log(subsetSum([3, 34, 4, 12, 5, 2], 30)); // false
