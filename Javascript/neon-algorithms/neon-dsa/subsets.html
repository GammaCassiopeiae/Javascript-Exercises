Subsets

Generate every subset of distinct numbers

Difficulty Medium
Time O(n · 2ⁿ)
Space O(n)
Pattern Backtracking

Given an array of distinct integers nums, return all possible subsets (the power set).

Backtrack by branching "include this element" vs "skip it" at every index, recording the path at each node.

JAVASCRIPT SOLUTION
function subsets(nums) {
    const result = [];

    function backtrack(start, path) {
        result.push([...path]);

        for (let i = start; i < nums.length; i++) {
            path.push(nums[i]);
            backtrack(i + 1, path);
            path.pop();
        }
    }

    backtrack(0, []);
    return result;
}

// Example
console.log(subsets([1, 2, 3]));
// → [[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]

> subsets([1,2,3]) → 8 subsets
