Time Based Key-Value Store

Set values with timestamps, get by time

Difficulty Medium
Set Time O(1)
Get Time O(log n)
Pattern Map + Binary Search

Design a store with set(key, value, timestamp) and get(key, timestamp) which returns the value set at the largest timestamp ≤ the given one (or "").

Store (timestamp, value) pairs per key in sorted order and binary-search for the newest pair not newer than the query time.

JAVASCRIPT SOLUTION
class TimeMap {
    constructor() {
        this.store = new Map(); // key → [[timestamp, value], ...]
    }

    set(key, value, timestamp) {
        if (!this.store.has(key)) {
            this.store.set(key, []);
        }
        this.store.get(key).push([timestamp, value]);
    }

    get(key, timestamp) {
        const pairs = this.store.get(key);
        if (!pairs || pairs.length === 0) {
            return "";
        }

        let left = 0;
        let right = pairs.length - 1;
        let best = "";

        while (left <= right) {
            const mid = Math.floor((left + right) / 2);

            if (pairs[mid][0] <= timestamp) {
                best = pairs[mid][1];
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return best;
    }
}

// Example
const tmap = new TimeMap();
tmap.set("foo", "bar", 1);
tmap.get("foo", 1);   // "bar"
tmap.get("foo", 3);   // "bar"  (newest ≤ 3)
tmap.set("foo", "bar2", 4);
tmap.get("foo", 4);   // "bar2"
tmap.get("foo", 5);   // "bar2"

> get("foo", 1) → "bar"

> get("foo", 4) → "bar2"
