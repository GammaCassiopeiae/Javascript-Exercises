Top K Frequent Elements

The k most frequent elements in an array

Difficulty Medium
Time O(n log k)
Space O(n)
Pattern Heap / Bucket Sort

Given an integer array nums and an integer k, return the k most frequent elements (any order).

Count frequencies, then bucket elements by frequency and read the highest buckets first.

JAVASCRIPT SOLUTION
function topKFrequent(nums, k) {
    const count = new Map();
    for (const num of nums) {
        count.set(num, (count.get(num) || 0) + 1);
    }

    // bucket[i] = elements appearing i times
    const buckets = new Array(nums.length + 1).fill(null);
    for (const [num, freq] of count) {
        (buckets[freq] = buckets[freq] || []).push(num);
    }

    const result = [];
    for (let freq = buckets.length - 1; freq >= 0; freq--) {
        if (!buckets[freq]) continue;

        for (const num of buckets[freq]) {
            result.push(num);
            if (result.length === k) return result;
        }
    }

    return result;
}

// Example
console.log(topKFrequent([1, 1, 1, 2, 2, 3], 2));
// → [1, 2]

> topKFrequent([1,1,1,2,2,3], 2) → [1, 2]
