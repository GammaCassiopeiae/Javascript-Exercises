Trapping Rain Water

Water trapped between elevation bars

Difficulty Hard
Time O(n)
Space O(1)
Pattern Two Pointers

Given non-negative height bars, compute how much rainwater can be trapped between them.

Two pointers track the running max on each side; water accumulates at each column equal to the smaller max minus its height.

JAVASCRIPT SOLUTION
function trap(height) {
    let left = 0;
    let right = height.length - 1;
    let maxLeft = 0;
    let maxRight = 0;
    let water = 0;

    while (left <= right) {
        if (maxLeft <= maxRight) {
            maxLeft = Math.max(maxLeft, height[left]);
            water += maxLeft - height[left];
            left++;
        } else {
            maxRight = Math.max(maxRight, height[right]);
            water += maxRight - height[right];
            right--;
        }
    }

    return water;
}

// Example
console.log(trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])); // 6
console.log(trap([4, 2, 0, 3, 2, 5]));                  // 9

> trap([0,1,0,2,1,0,1,3,2,1,2,1]) → 6

> trap([4,2,0,3,2,5]) → 9
