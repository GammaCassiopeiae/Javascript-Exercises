Unique Binary Search Trees

Count BSTs formed from 1…n

Difficulty Medium
Time O(n²)
Space O(n)
Pattern Dynamic Programming · Catalan

Given an integer n, return the number of structurally unique BSTs that store the values 1 … n.

For each possible root i, multiply the count of left BSTs (i-1 nodes) by right BSTs (n-i nodes). These are the Catalan numbers.

JAVASCRIPT SOLUTION
function numTrees(n) {
    const dp = new Array(n + 1).fill(0);
    dp[0] = 1;   // empty tree
    dp[1] = 1;   // single node

    for (let nodes = 2; nodes <= n; nodes++) {
        for (let root = 1; root <= nodes; root++) {
            const left = root - 1;
            const right = nodes - root;
            dp[nodes] += dp[left] * dp[right];
        }
    }

    return dp[n];
}

// Example
console.log(numTrees(1)); // 1
console.log(numTrees(2)); // 2
console.log(numTrees(3)); // 5
console.log(numTrees(4)); // 14

> numTrees(3) → 5

> numTrees(4) → 14
