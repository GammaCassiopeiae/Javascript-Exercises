Unique Paths

Count paths from top-left to bottom-right

Difficulty Medium
Time O(m · n)
Space O(n)
Pattern Dynamic Programming

A robot moves only right or down from a grid's top-left corner. Count the distinct paths to the bottom-right of an m × n grid.

Each cell's path count is the sum of the cell above and the cell to the left — collapse to one row for O(n) space.

JAVASCRIPT SOLUTION
function uniquePaths(m, n) {
    const dp = new Array(n).fill(1);  // first row is all 1s

    for (let row = 1; row < m; row++) {
        for (let col = 1; col < n; col++) {
            dp[col] += dp[col - 1];
        }
    }

    return dp[n - 1];
}

// Example
console.log(uniquePaths(3, 7)); // 28
console.log(uniquePaths(3, 2)); // 3

> uniquePaths(3, 7) → 28

> uniquePaths(3, 2) → 3
