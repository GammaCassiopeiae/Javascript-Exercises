Valid Parentheses

Check that brackets close in the right order

Difficulty Easy
Time O(n)
Space O(n)
Pattern Stack

Given a string s containing just the characters ()[]{}, determine if the input string is valid.

Push opening brackets onto a stack; pop and match when a closing bracket appears. The stack must be empty at the end.

JAVASCRIPT SOLUTION
function isValid(s) {
    const stack = [];
    const pairs = {
        ')': '(',
        ']': '[',
        '}': '{'
    };

    for (const char of s) {
        if (char in pairs) {
            const top = stack[stack.length - 1];
            if (top === pairs[char]) {
                stack.pop();
            } else {
                return false;
            }
        } else {
            stack.push(char);
        }
    }

    return stack.length === 0;
}

// Example
console.log(isValid("()[]{}")); // true
console.log(isValid("(]"));     // false

> isValid("()[]{}") → true

> isValid("(]") → false
