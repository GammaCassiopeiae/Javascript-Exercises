Validate Binary Search Tree

Check that a tree satisfies BST ordering

Difficulty Medium
Time O(n)
Space O(n)
Pattern DFS · Bound Constraints

Given the root of a binary tree, determine if it is a valid BST — left subtree values must be strictly less, right subtree values strictly greater than the node.

Pass a valid min/max range down the recursion and verify each node stays within its bounds.

JAVASCRIPT SOLUTION
function isValidBST(root) {
    function validate(node, min, max) {
        if (node === null) {
            return true;
        }

        if (node.val <= min || node.val >= max) {
            return false;
        }

        return validate(node.left, min, node.val) &&
               validate(node.right, node.val, max);
    }

    return validate(root, -Infinity, Infinity);
}

// Example
//       2          → valid BST
//      / \
//     1   3

//       5          → NOT valid (4 is > 3)
//      / \
//     1   4
//        / \
//       3   6

> isValidBST(root([2,1,3])) → true

> isValidBST(root([5,1,4,null,null,3,6])) → false
