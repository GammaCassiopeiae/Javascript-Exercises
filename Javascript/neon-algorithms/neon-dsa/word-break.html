Word Break

Can the string be segmented into dictionary words?

Difficulty Medium
Time O(n²)
Space O(n)
Pattern Dynamic Programming

Given a string s and a dictionary wordDict, return true if s can be segmented into one or more dictionary words.

dp[i] says whether s[0..i] is segmentable; extend from every reachable position to edges in the dictionary.

JAVASCRIPT SOLUTION
function wordBreak(s, wordDict) {
    const words = new Set(wordDict);
    const dp = new Array(s.length + 1).fill(false);
    dp[0] = true;

    for (let i = 1; i <= s.length; i++) {
        for (let j = 0; j < i; j++) {
            if (dp[j] && words.has(s.slice(j, i))) {
                dp[i] = true;
                break;
            }
        }
    }

    return dp[s.length];
}

// Example
console.log(wordBreak("leetcode", ["leet", "code"])); // true
console.log(wordBreak("catsandog", ["cats", "dog", "sand", "and", "cat"])); // false

> wordBreak("leetcode", ["leet","code"]) → true

> wordBreak("catsandog", ["cats","dog","sand","and","cat"]) → false
